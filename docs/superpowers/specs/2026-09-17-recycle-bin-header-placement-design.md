# 回收站顶部位置调整

## 目标

将“回收站”从装备筛选栏移动到顶部操作区，并放在“全部重命名”按钮左侧。将装备库流派范围开关的“可用”文案改为“当前流派”。

## 范围

- 在 `equip-recycle-bin.js` 将动态创建的按钮插入 `#rename-all-btn` 左侧。
- 保留现有的按钮 ID、文本、禁用状态、计数更新、弹窗和回收逻辑。
- 移除只服务于筛选栏位置的右侧外边距。
- 筛选栏仍保持当前的六列布局，避免“录入装备”换行回归。
- 保留“全流派”文案和现有筛选状态，仅将启用筛选时的“可用”文案改为“当前流派”。

## 验证

- 扩展浏览器布局回归测试：回收站位于“全部重命名”左侧，且“录入装备”保留在筛选栏首行。
- 验证流派范围开关在启用和停用状态分别显示“当前流派”和“全流派”。
- 运行回收站逻辑测试、调率站自定义保护检查和 Hugo 构建。
