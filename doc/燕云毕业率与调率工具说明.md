# 燕云毕业率与调率工具说明

## 文档目的

本文用于说明博客内《燕云十六声》相关工具页中“毕业率计算”和“调率对比”部分的当前实现、使用方式与后续扩展方向，方便后续继续维护、迭代和对外介绍。

当前工具入口：

- 毕业率工具：`/tools/yysls-graduation/`
- 装备管理器：`/tools/yysls-armory/`

本文重点介绍毕业率工具，以及其中已经具备的调率 / 对比能力。

---

## 一、工具定位

这个工具页的目标，不是重新手写一套简化公式，而是尽量保留原始 Excel 工作簿里的输入结构、表间引用和输出结果，把它迁移成可以直接在网页使用的版本。

它适合完成这些事情：

- 快速录入当前战斗环境和面板参数
- 直接读取原工作簿中的毕业率结果
- 在网页里做小范围属性微调
- 对比“当前装备”和“候选装备”的收益变化
- 在不打开 Excel 的情况下完成日常调率

它本质上是一个“原 Excel 工作簿网页化”的轻量分析工具。

---

## 二、当前页面能力

### 1. 双版本工作簿切换

当前页面支持两个版本：

- 破竹鸢
- 破竹尘

页面顶部可以通过“计算器版本”下拉框切换。切换后，网页会自动加载对应版本的 JSON 工作簿数据，并使用那一套输入定义与公式结果。

目前对应的数据来源是：

- `workbook-yuan.json`
- `workbook-chen.json`

这两个 JSON 文件由原始 Excel 工作簿导出而来。

### 2. 原 Excel 公式驱动

网页不是写死结果，也不是只搬了一部分公式，而是在前端加载工作簿 JSON 后，用一个轻量公式引擎实时求值。

当前已实现的核心能力包括：

- 单元格引用
- 跨表引用
- 区域引用
- 整列范围引用
- `IF`
- `VLOOKUP`
- `MAX`
- `MIN`
- `AND`
- `OR`
- `SUM`

同时，页面会在输入变化后按依赖关系失效缓存，再重新读取受影响的结果格，尽量保持和原 Excel 的输出一致。

### 3. 主输入区

页面左侧主输入区已经整理出了当前常用的可编辑输入格，主要包括：

- 战斗环境
- 目标选择
- 心法开关
- 吃药与额外增益
- 外功与目标参数
- 破竹与无相参数
- 双暴与增伤参数
- 武器与奇术增伤参数

这些输入项在网页中修改后，会直接回写到当前工作簿 `期望` 页对应的输入格，再触发结果刷新。

### 4. 关键结果展示

当前页面右侧会显示几项核心输出，直接读取工作簿里的结果格：

- 毕业率：`期望!C40`
- 总伤：`期望!C30`
- DPS：`期望!C35`
- 用时：`期望!C28`
- 对比变化：`期望!Q2`
- 当前目标：`期望!F7`

其中：

- “毕业率”是页面最核心的结果项
- “对比变化”是做调率时最直观的收益参考
- “当前目标”可以帮助确认当前计算到底落在哪个目标模板上

### 5. 面板回显

页面还提供了一块“面板回显”区域，用于读取当前工作簿里的关键值并显示出来，便于确认输入是否真的生效。

当前回显的主要内容包括：

- 主属性
- 目标
- 最小 / 最大外功
- 外功穿透
- 最小 / 最大破竹
- 破竹穿透
- 精准率
- 会心率
- 会意率
- 首领增伤

这部分更像“校验区”，可以避免出现“表单看起来改了，但没有改到预期单元格”的情况。

### 6. 恢复默认值

页面提供“恢复表内默认值”按钮，可以把当前版本下所有网页输入还原到工作簿原始默认值。

适合以下场景：

- 一轮试算结束后重置参数
- 回到原始参考模板
- 切换思路后快速重开

## 三、调率 / 对比能力

这里的“调率”，主要指围绕毕业率、对比收益和属性变化做快速试算，而不是单纯记录装备。

### 1. 隐藏对比区

当前毕业率页面已经把原工作簿里用于“当前装备 / 对比装备”的隐藏输入区搬到了网页里，对应原表中的 `L2:P26` 区域。

页面上会把它显示成一张对比表，字段结构为：

- 属性名称
- 当前 A
- 当前 B
- 对比 A
- 对比 B

这块会随着“破竹鸢 / 破竹尘”切换而一起切换。

### 2. 对比结果输出

调率最直接的结果是“对比变化”，当前页面读取的是：

- `期望!Q2`

这个值可以理解为：

- 当前装备与候选装备之间的结果变化比例
- 某次属性调整带来的提升或下降

适合拿来判断：

- 换一件装备值不值
- 某条词条换成另一条收益如何
- 会心、会意、增伤、穿透之间的相对平衡

### 3. 当前更适合的使用方式

网页版当前最适合的流程是：

1. 选择版本与目标
2. 填入主输入区参数
3. 在隐藏对比区填入当前装备和候选装备
4. 观察毕业率、DPS、总伤与对比变化
5. 判断这次调整是否值得

它更偏“快速试错”和“日常验证”，而不是自动寻优。

### 4. 当前边界

当前调率能力已经够用来做个人日常试算，但仍然属于“工作簿网页化”阶段，暂时还没有发展成完整自动优化器。

当前未实现的能力包括：

- 自动搜索最优词条组合
- 自动推荐最优装备组合
- 多方案批量比较
- 从装备库一键带入属性
- 与装备管理器自动联动

## 四、数据与实现结构

### 1. 原始数据来源

当前原始工作簿位于项目中的 `yysls/` 目录，主要包括：

- 破竹鸢 4.3 工作簿
- 破竹尘 4.5 工作簿

### 2. 导出脚本

项目提供了一个导出脚本，用于把 Excel 工作簿转换成网页可读的 JSON：

- `scripts/extract_yysls_workbook.py`

脚本会读取原始工作簿，并导出：

- 工作簿元信息
- sheet 顺序
- 各工作表的单元格内容
- 单元格公式
- 工作表边界信息

导出的目标文件位于：

- `static/tools/yysls-graduation/workbook-yuan.json`
- `static/tools/yysls-graduation/workbook-chen.json`

### 3. 页面实现

毕业率工具页面本体位于：

- `static/tools/yysls-graduation/index.html`
- `static/tools/yysls-graduation/app.js`

其中：

- `index.html` 负责页面结构和视觉样式
- `app.js` 负责工作簿加载、公式引擎、输入渲染、结果刷新和对比区逻辑

## 五、与装备管理器的关系

博客里的两个工具当前是互补关系：

- 装备管理器负责“记录、导入、筛选装备资产”
- 毕业率工具负责“录入属性、读取毕业率、做对比试算”

目前它们还是两套独立页面，还没有自动打通。

比较理想的后续方向是：

1. 在装备管理器中维护账号装备库
2. 从装备库选择一套装备
3. 自动汇总属性
4. 一键带入毕业率工具
5. 直接读取毕业率与调率结果

这样就能形成更完整的配装闭环。

---

## 六、当前优点与限制

### 1. 优点

- 尽量保留原 Excel 的计算逻辑
- 网页即可使用，不依赖本地 Excel
- 支持破竹鸢 / 破竹尘双版本切换
- 支持实时调参和结果刷新
- 已经具备基础调率 / 对比能力

### 2. 限制

- 仍然依赖原工作簿的数据结构和公式质量
- 主要是手动输入，不是自动配装
- 尚未和装备管理器联动
- 暂无批量方案比较、词条排行和自动推荐

---

## 七、后续可扩展方向

后续可以继续补充这些能力：

- 装备库与毕业率工具联动
- 方案保存与方案切换
- 单件装备收益排行
- 词条优先级分析
- 一键导入当前方案
- 分享链接生成
- 更多流派 / 赛季工作簿版本切换

---

## 八、一句话总结

这个“燕云毕业率与调率工具”，本质上是一个把原始 Excel 工作簿迁移到网页端的轻量分析工具。它当前已经支持双版本切换、主输入区调参、关键结果读取和基础装备对比，适合作为整个《燕云十六声》工具站中的计算核心。
