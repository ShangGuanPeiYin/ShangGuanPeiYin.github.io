# 软件需求规格说明

> 编写日期：2026-11-08。代码基线：`fa6a1a9b9de81f81415e710f7131d6e827bc598f`。业务依据：本轮用户逐项确认。实现与验证状态见 [SRS](SRS.md) 和 [验证说明](verification.md)。

本文件记录用户确认的目标行为。状态以文末差异表为准；未列入差异表也不自动意味着通过动态验收。术语和机制引用 [GDD](GDD.md)，实现证据见 [SDS](SDS.md)。

## 装备与计算

| 编号 | 需求与可观察验收条件 |
| --- | --- |
| SRS-EQUIP-001 | 支持角色隔离、手动录入、编辑及 OCR 录入；保持稳定装备身份。OCR 结果需按实际字段校核，不能视为识别准确率保证。 |
| SRS-EQUIP-002 | 判重比较部位、武器类型、等级、金紫类别、流派适用范围（包括流向）、主副词条类型组合、承音状态及完整转律设置。任一不同分别保留；其余一致后按 GDD-QUALITY-001 择优。忽略定音和副词条顺序；比较选定转律词条须语义对应，不只比较行号。这不要求转律改变顺序。 |
| SRS-EQUIP-003 | 装备库筛选仅改变列表显示，不改变搜索范围。删除装备后仍保留方案，槽位标缺失并取消该装备模拟；不自动替换、不用回收站装备计算。不完整配装的结果须注明不完整。 |
| SRS-CALC-001 | 使用 GDD-CALC-001 输出毕业率，超过 100% 保留，不额外处理。引擎未就绪或计算失败不宣称获得有效计算结果。 |
| SRS-ANALYSIS-001 | 词条收益、培养、转律与单件比较以当前方案模拟后状态为起点。替换目标装备时先移除旧装备及其模拟效果，其余条件保持一致。 |
| SRS-ANALYSIS-002 | 数量模式按 GDD-MANUAL-001 校验可实现性；不合法时提示原因，不把非法组合输出为有效毕业方案。手填面板允许自由试算。 |

## 搜索

| 编号 | 需求与验收条件 |
| --- | --- |
| SRS-SEARCH-001 | 只使用当前角色实际装备库及其合法承音、转律变体；排除理论装备、其他角色和回收站。同一实体不能同时占两个位置。 |
| SRS-SEARCH-002 | 严格执行 GDD-CHENGYIN-002 阈值与用户额度、武器及面板等显式限制。额度指新增需承音件数；无解不放宽条件。 |
| SRS-SEARCH-003 | 三种模式按 GDD-TRANSMUTATION-001～004 生成候选，保留原状、遵守排除目标，按 GDD-DINGYIN-001 满定音评价。 |
| SRS-SEARCH-004 | 按未四舍五入毕业率降序，再按需承音件数升序，再按实际改变词条的装备数升序。勾选可转律但保持原词条不计转律操作。100.004% 必须排在 100.001% 前，不因显示相同而比较成本。 |
| SRS-SEARCH-005 | 相同装备组合与承音安排的转律变体只保留最高毕业率；不同承音安排分别保留；完全等价装备替换得到的方案合并，实体占用约束仍成立。当前显示上限为 20 套，不把变量名 top10Builds 解读为十套。 |
| SRS-SEARCH-006 | 遗传搜索不承诺全局最优；穷举只对实际完整遍历的有效候选范围作保证，必须披露预筛选或剪枝限制。 |
| SRS-SEARCH-007 | 取消后停止本次搜索并丢弃全部中途结果。保留上次已完成结果并标明旧条件；保存的配装不受影响。尚无旧结果时不能伪造结果。 |

## 方案

| 编号 | 需求与验收条件 |
| --- | --- |
| SRS-SCHEME-001 | 保存装备引用、承音／转律模拟及计算环境；应用后模拟数值生效，装备库原始数据不被改写。搜索方案继续满定音计算，重载后仍保持。 |
| SRS-SCHEME-002 | 读取最新装备数值；实际承音后消除重复模拟并减少需承音计数。原转律安排失效则取消、恢复真实属性并提示，其他安排保留，不把旧模拟套到同一行的新词条。 |
| SRS-SCHEME-003 | 重开方案恢复流派版本、心法、套装、弓、武库、赛季等保存设置；用当前引擎与基准重算，不冻结历史结果。原版本不可用提示重选，不静默替换。 |

## 数据与恢复

| 编号 | 需求与验收条件 |
| --- | --- |
| SRS-DATA-001 | 区分单角色装备导入、完整备份及 Excel 导出；完整备份保留角色、稳定装备身份、方案、转律和手动分析数据，引用关系可恢复。 |
| SRS-DATA-002 | 完整恢复整体替换，包括删除备份以外角色。恢复前说明覆盖范围并保留恢复前数据以便撤回。当前实现不同，见 D08。 |
| SRS-DATA-003 | 整份先校验；已识别旧格式先转换再校验。合法空槽允许，悬空装备引用整份拒绝并指出角色、方案及位置；失败不部分覆盖。 |
| SRS-DATA-004 | 多设备冲突暂停自动覆盖，保留双方数据，由用户选择本地或云端，不自动合并或单凭最后上传时间决定正确版本。 |
| SRS-DATA-005 | 回收站恢复只放回装备库，不自动穿戴；当前保留时间为 15 天。当前界面与实现静态核对，端到端删除恢复未验证。 |

## 非功能约束

单一 Q7 数值边界遵守项目规则；共享计算入口避免分析口径漂移。用户数据按角色隔离，完整恢复避免部分写入。没有实测数据时，不设定或宣称性能提升、搜索最优性、识别准确率、浏览器兼容率或云端隔离已验收。验收证据见 [verification](verification.md)。
