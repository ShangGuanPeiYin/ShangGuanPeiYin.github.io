# 调率站产品需求文档（PRD）

> 本文档从现有代码、运行行为与维护制度中**反向还原**调率站的产品定义，用于认识产品全貌并指导后续演进。
> 视角定位：**现状盘点 + 演进方向**。只描述"现在是什么、应该是什么、未来可以往哪走"，不替代技术文档。

## 文档

- [调率站产品需求文档（PRD）](PRD.md) —— 单文件完整 PRD，共 10 章：

1. 产品概述
2. 用户与场景
3. 核心流程
4. 功能需求
5. 数据与依赖
6. 非功能需求
7. 边界与非目标
8. 指标与验收
9. 演进路线图
10. 附录

## 与其他文档的关系

| 文档 | 定位 | 与 PRD 的分工 |
| --- | --- | --- |
| `doc/调率站产品与计算逻辑.md` | 业务规则与计算口径 | PRD 的需求侧来源；PRD 只引用结论，不重复推导 |
| `doc/调率站代码实现说明.md` | 技术架构与实现 | PRD 的实现侧来源；PRD 不写代码级细节 |
| `doc/tiaolv-local-customizations.md` | 本地定制保护清单 | PRD 的治理红线来源 |
| `AGENTS.md` | AI 工作约定 | 治理制度来源 |

> 原则：产品规则、技术实现、转律机制、定制清单、PRD 各自独立维护，同一事实避免多处漂移。PRD 描述"要什么/为什么"，技术文档描述"怎么做"。

## 术语

「毕业率」= 当前配置 DPS ÷ 理论毕业 DPS × 100%；「承音」「定音」「转律」等术语见 PRD.md 第 10 章附录。
