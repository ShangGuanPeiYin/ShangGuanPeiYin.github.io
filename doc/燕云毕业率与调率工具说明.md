# 燕云毕业率与调率工具说明

## 文档目的

本文用于说明博客内《燕云十六声》相关工具页的定位、核心功能与当前实现范围，方便后续继续扩展、维护和对外介绍。

当前工具入口：

- 毕业率工具：`/tools/yysls-graduation/`
- 装备管理器：`/tools/yysls-armory/`

本文重点介绍其中的“毕业率”和“调率/对比”能力。

---

## 一、工具定位

这个工具页的目标，不是重新发明一套全新的计算规则，而是尽量保留原始 Excel 工作簿中的输入结构、公式关系和输出结果，把它迁移成一个可以在网页里直接使用的版本。

它适合用来做几件事：

- 快速录入当前面板与战斗环境
- 读取原工作簿中的毕业率结果
- 对比当前装备和候选装备的变化
- 在不打开 Excel 的情况下做日常调率
- 为后续装备管理器、配装分析页提供统一入口

---

## 二、毕业率工具功能介绍

### 1. 双版本工作簿切换

当前页面支持两个计算版本：

- 破竹鸢
- 破竹尘

页面顶部的“计算器版本”下拉框可以直接切换。切换后，网页会加载对应工作簿的数据定义、输入项和公式输出。

这意味着：

- 不同流派或版本可以共用同一个网页入口
- 每套公式逻辑互不混淆
- 后续可以继续新增新的工作簿版本

### 2. 原 Excel 公式驱动

网页版不是手写一组简化公式，而是读取从原工作簿导出的 JSON 数据，在前端构建一个轻量公式引擎，实时计算结果。

当前已支持的核心公式能力包括：

- 单元格引用
- 跨表引用
- 区域引用
- 整列范围引用
- `IF`
- `VLOOKUP`
- `MAX`
- `MIN`
- `AND`
- `OR`
- `SUM`

这使得网页结果尽量与原 Excel 输出保持一致。

### 3. 主输入区

当前毕业率页面已经把原工作簿中常用的主输入格整理成可交互表单，主要包括：

- 战斗环境
- 目标选择
- 心法开关
- 吃药与额外增益
- 外功与目标参数
- 破竹与无相参数
- 双暴与增伤参数
- 武器与奇术增伤参数

这些输入项在网页里修改后，会立即回写到当前工作簿对应的输入格，再触发整套输出刷新。

### 4. 关键结果展示

当前页面会直接读取工作簿中的关键输出格，主要包括：

- 毕业率：读取 `期望!C40`
- 总伤：读取 `期望!C30`
- DPS：读取 `期望!C35`
- 用时：读取 `期望!C28`
- 装备对比变化：读取 `期望!Q2`

其中“毕业率”是当前页面最核心的结果展示项，可以用于判断当前属性距离理想目标的完成度。

### 5. 面板回显

页面右侧提供了“面板回显”区域，用来显示当前网页输入实际回写后的部分关键值，方便确认：

- 当前输入是否生效
- 当前目标选择是否正确
- 输入参数是否和预期一致

这块主要起到校验作用，避免出现“看起来改了，实际上没有改到目标格”的情况。

### 6. 恢复默认值

页面提供“恢复表内默认值”按钮，可以把当前版本下的输入还原到工作簿原始默认值，适合：

- 重置实验参数
- 回到标准参考面板
- 快速重新开始一轮调率

## 三、调率工具功能介绍

这里的“调率”，主要指围绕毕业率、对比收益、属性变化做快速试算，而不是单纯记录面板。

### 1. 当前装备 / 对比装备隐藏区

当前毕业率页面已经保留了一块与原工作簿对应的隐藏对比区，对应原表里的 `L2:P26` 输入区域。

这块的作用是：

- 填入“当前装备”属性
- 填入“对比装备”属性
- 读取两组装备在工作簿公式下的差值变化

它更适合做：

- 换一件装备值不值
- 某条词条换成另一条是否提升
- 会心、会意、增伤、穿透之间如何平衡

### 2. 对比变化输出

调率最直接的结果是“装备对比变化”，当前页面读取的是：

- `期望!Q2`

这个值可以理解为：

- 当前装备与对比装备之间的结果变化比例
- 某次属性调整对结果的提升或下降

适合拿来做小范围的词条收益判断。

### 3. 快速试错

网页版调率最大的优势，是不需要来回打开 Excel、修改公式区域或担心破坏原表。

当前流程更适合：

1. 选择目标
2. 输入当前属性
3. 微调一项或几项词条
4. 观察毕业率、DPS、对比变化
5. 判断这次调整是否值得

### 4. 当前调率能力的边界

当前版本更偏“工作簿网页化”，已经适合个人日常调率，但还没有做成完整的自动优化器。

目前没有实现的能力包括：

- 自动搜索最优词条组合
- 自动推荐最优装备组合
- 多方案批量比较
- 基于装备库的一键带入
- 与装备管理器的自动联动

这些都可以作为下一阶段扩展方向。

## 四、当前实现特点

### 1. 优点

- 保留原 Excel 的计算逻辑
- 网页可直接使用，不依赖本地 Excel
- 支持双版本切换
- 支持实时调参和结果回显
- 适合个人日常调率和对比

### 2. 当前限制

- 仍然依赖原工作簿的数据结构
- 主要是手动输入，不是自动配装
- 暂未与装备管理器打通
- 暂未加入 OCR、评分、自动毕业率推荐

---

## 五、与装备管理器的关系

博客里的装备管理器和毕业率工具，是两条互补能力：

- 装备管理器负责“记录和筛选装备资产”
- 毕业率工具负责“输入属性并读取毕业率结果”

后续比较理想的方向是：

1. 先在装备管理器中维护账号装备库
2. 从装备库选择一套装备
3. 自动汇总属性
4. 一键带入毕业率工具
5. 读取毕业率、DPS 和调率结果

这样两个工具就会形成完整闭环。

## 七、一句话总结

这个“燕云毕业率与调率工具”，本质上是一个基于原始 Excel 工作簿公式迁移到网页端的轻量分析工具，用来做毕业率查看、属性调率和装备对比，适合作为整个《燕云十六声》装备工具站里的计算核心。
