# 调率工具产品需求文档

> 编写日期：2026-11-08。代码基线：`fa6a1a9b9de81f81415e710f7131d6e827bc598f`。业务依据：本轮用户逐项确认。实现与验证状态见 [SRS](SRS.md) 和 [验证说明](verification.md)。

## 产品定位

调率工具帮助玩家维护装备档案，理解装备组合形成的面板与输出，并在资源限制内选择配装。计算分析与配装决策是两个同等重要的目标：既能回答“这套面板怎样”，也能回答“现有装备怎样搭配”。毕业率含义由 [GDD](GDD.md) 定义，软件行为与差异由 [SRS](SRS.md) 约束。

核心使用者是需要比较配装、承音和转律方案的玩家。多角色用户需要数据隔离，多设备用户需要可控的备份恢复；开发者需要能追溯计算依据和实现边界。这些场景不等于已经完成用户规模、性能或满意度调查。

## 核心流程

1. 选择角色与流派，通过手动录入、OCR 或数据导入建立装备档案。
2. 选择装备及计算环境，查看面板、秒伤和毕业率。
3. 使用词条收益、培养建议、转律建议、单件对比分析改动收益；通过手填面板或合法词条组合试算。
4. 设置需承音上限、转律模式等搜索条件，从当前角色装备库寻找方案。
5. 比较输出和操作投入，应用并保存方案。方案模拟不表示游戏中已经完成培养。
6. 维护真实装备状态，重算方案；导出完整备份，必要时通过云端在设备间迁移。

## 功能范围

| 能力 | 产品意义 | 需求入口 |
| --- | --- | --- |
| 角色与装备管理、OCR、筛选、回收站 | 建立并维护实际装备档案 | SRS-EQUIP、SRS-DATA |
| 面板、秒伤与毕业率 | 给组合一个明确且有条件的输出评价 | SRS-CALC |
| 六类分析：手动填写、最佳配装、词条优先级、培养、转律、单件对比 | 支持现状分析和培养决策 | SRS-ANALYSIS、SRS-SEARCH |
| 方案管理 | 保存装备选择、模拟安排和计算环境 | SRS-SCHEME |
| JSON、Excel 导出及可选云备份 | 迁移数据、复核输入与恢复档案 | SRS-DATA |

最佳配装不受装备库显示筛选影响；搜索结果是固定计算条件下的比较。尤其搜索始终按满定音评价，应用后保留这一方案条件。遗传结果是本次搜索找到的较好结果，不能宣传为已证明的全局最优。

## 边界与成功标准

本工具使用外部作者已经求得的最佳毕业方案参考秒伤，不自行重新求解毕业基准。超过 100% 正常显示，不额外处理。旧 Excel 数值可能落后于游戏版本；本次文档工作不更新它们，不宣称完成游戏数值验真。

工具不执行游戏内培养，不把模拟结果自动写成真实装备，不把手动理论装备加入实际仓库搜索。云端用于可选备份，计算和即时档案以浏览器本地为主。

首版成功标准是术语一致、规则可追溯、用户限制不被静默放宽、当前实现与目标差异可查。具体可观察条件见 SRS，证据见验证说明。未设定未经用户确认的响应时限、用户增长目标、未来功能或重构路线图。
