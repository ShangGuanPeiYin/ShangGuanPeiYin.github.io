# 燕云十六声装备搭配器详细说明书

> 本文是面向使用者的功能说明书，全面介绍装备搭配器的使用方法、核心功能、数据结构和典型场景。
>
> 最后更新时间：2026年5月

---

## 一、概述

### 1.1 装备搭配器是什么

装备搭配器是连接"装备管理"和"毕业率计算"的桥梁。它的核心作用是：把装备管理器里零散录入的单件装备，真正组合成一整套能用的配装方案。

你可以把它理解成一个**"网页里的配装台"**，主要用来回答这些问题：

- 这套流派应该带哪两把武器？
- 8 个槽位分别放哪一件更合适？
- 换掉某一个部位后，整套词条会变成什么样？
- 同一个角色是否要保存多套不同用途的方案？
- 我想要 8 条会心、3 条精准，有哪些穿搭组合能满足？

### 1.2 入口地址

- 装备搭配器：`/tools/yysls-outfitter/`
- 数据来源：装备管理器（`/tools/yysls-armory/`）

### 1.3 与装备管理器的关系

装备搭配器**不直接录入装备**，而是读取装备管理器保存在浏览器 `localStorage` 中的数据。

```
┌─────────────────┐     localStorage     ┌─────────────────┐
│  装备管理器      │  ──────────────────→ │  装备搭配器      │
│  (录入单件装备)  │                      │  (组合成套方案)  │
└─────────────────┘                      └─────────────────┘
         │                                        │
         │         ┌─────────────────┐            │
         └───────→ │  毕业率计算器    │ ←──────────┘
                   │  (数值试算)      │
                   └─────────────────┘
```

## 三、顶部控制栏

### 3.1 角色选择

- **数据来源**：直接读取装备管理器中保存的所有角色
- **切换角色**：自动加载该角色的装备库和已保存的搭配方案
- **首次使用**：如果装备管理器中没有角色，搭配器会提示"请先前往装备管理器添加角色和装备"

### 3.2 流派选择

页面顶部可选择当前流派。选定流派后：

- 武器1、武器2 槽位自动限制为该流派对应的武器类型
- 候选装备列表自动过滤为适用该流派的装备
- 词条搜索时遵循流派的双武器规则

**10 个分支流派与武器对应关系：**

| 流派 | 武器1 | 武器2 |
|------|-------|-------|
| `鸣金·虹` | 剑 | 枪 |
| `鸣金·影` | 剑 | 枪 |
| `裂石·威` | 陌刀 | 枪 |
| `裂石·钧` | 唐横刀 | 陌刀 |
| `牵丝·玉` | 伞 | 扇 |
| `牵丝·霖` | 伞 | 扇 |
| `牵丝·翊` | 舞绫鼓 | 扇 |
| `破竹·风` | 双刀 | 绳镖 |
| `破竹·尘` | 伞 | 绳镖 |
| `破竹·鸢` | 拳甲 | 绳镖 |

> 注意：武器类型在内部数据中统一称为"绳标"，界面显示为"绳镖"。

### 3.3 方案管理

| 操作 | 说明 |
|------|------|
| **方案下拉框** | 切换已保存的方案，自动填充 8 槽位 |
| **方案名称输入框** | 修改当前方案的名称 |
| **保存方案** | 将当前 8 槽位搭配保存到本地，同一角色下可保存多套 |
| **删除方案** | 删除当前选中的方案 |
| **新建方案** | 创建一个空的全新方案 |

**方案存储格式：**
```json
{
  "id": "uuid",
  "name": "首领输出方案",
  "className": "破竹·尘",
  "slots": {
    "武器1": "装备id",
    "武器2": "装备id",
    "环": "装备id",
    ...
  },
  "createdAt": "2026-05-01T12:00:00.000Z",
  "updatedAt": "2026-05-10T15:30:00.000Z"
}
```

## 四、8槽位穿搭区域

### 4.1 槽位说明

固定维护 8 个槽位：

| 槽位 | 类型 | 说明 |
|------|------|------|
| 武器1 | 武器 | 流派对应的第一把武器 |
| 武器2 | 武器 | 流派对应的第二把武器 |
| 环 | 首饰 | 戒指部位 |
| 佩 | 首饰 | 佩饰部位 |
| 冠胄 | 防具 | 头部防具 |
| 胸甲 | 防具 | 胸部防具 |
| 胫甲 | 防具 | 腿部防具 |
| 腕甲 | 防具 | 手部防具 |

### 4.2 操作流程

1. **点击槽位**：该槽位变为激活状态（高亮），左侧候选列表自动过滤为该槽位可用装备
2. **放入装备**：在左侧候选列表中点击"放入槽位"按钮
3. **移除装备**：点击槽位卡片上的"移除"按钮，或直接点击候选列表中已装备的装备
4. **切换槽位**：点击其他槽位即可切换激活状态

### 4.3 双武器约束

选定流派后，武器槽位会自动限制：

- 武器1 只能选流派武器规则中的**第一把武器**类型
- 武器2 只能选流派武器规则中的**第二把武器**类型

**示例：**
- `破竹·尘` 的武器1 只能选 `伞`，武器2 只能选 `绳镖`
- `裂石·钧` 的武器1 只能选 `唐横刀`，武器2 只能选 `陌刀`

如果当前已装备的武器不符合新流派的规则，切换流派时会**自动清空**这两个武器槽位。

## 五、候选装备列表

### 5.1 数据来源

候选装备直接读取装备管理器保存的本地数据，不需要重复录入。

### 5.2 部位筛选

页面左下方有一排胶囊按钮，可按部位快速筛选：

- **全部**：显示所有装备
- **武器1 / 武器2**：显示对应武器类型的装备
- **环 / 佩 / 冠胄 / 胸甲 / 胫甲 / 腕甲**：显示对应部位的装备

点击槽位后，筛选会自动切换为该槽位对应的部位。

### 5.3 装备卡片信息

每张装备卡片显示：
- 装备名称
- 武器类型（仅武器装备）
- 主词条（类型 + 数值）
- 副词条列表（类型 + 数值）
- 定音词条（类型 + 数值，如有）
- "放入槽位"按钮

### 5.4 搜索过滤

候选列表上方有一个搜索框，支持按装备名称关键词实时过滤。

## 六、词条汇总区

### 6.1 全部词条

自动统计当前已上阵 8 件装备的所有词条，按以下规则分类排序：

1. **普通词条**（精准率、会心率、会意率、外功攻击等）
2. **武器专属词条**（剑武学增效、枪武学增效等）——排在最后

每项显示：
- **词条名称**
- **出现的条数**（如 8 条）
- **数值总和**（如 124.7%、776.9 等）

### 6.2 百分比词条 vs 数值词条

系统会自动识别百分比词条和数值词条：

| 类型 | 示例 | 显示格式 |
|------|------|---------|
| 百分比词条 | 精准率、会心率、会意率、全武学增效、对首领单位增伤、指定武学技能增伤、各类武器武学增效 | 保留 1 位小数，末尾 `.0` 会省略（如 `47.5%`） |
| 数值词条 | 最小外功攻击、最大外功攻击等 | 保留 1 位小数，末尾 `.0` 会省略（如 `776.9`） |

### 6.3 方案信息

显示当前方案的名称和已上阵槽位数量（如"已上阵 6 / 8"）。

## 七、词条条数搜索 ⭐（核心功能）

这是装备搭配器最具特色的功能。它可以**按目标词条条数自动反推**可行的穿搭方案。

### 7.1 搜索条件设置

**添加条件：**
1. 点击"添加条件"按钮
2. 选择目标词条类型（下拉菜单中只显示当前装备库中实际存在的可统计词条）
3. 输入目标条数（正整数，最小为 1）
4. 可重复添加多个条件

**匹配模式：**

| 模式 | 说明 |
|------|------|
| **至少满足**（默认） | 实际条数 ≥ 目标条数即可 |
| **刚好等于** | 实际条数必须恰好等于目标条数 |

**去重规则：**
- 同一词条类型不能重复添加
- 添加新条件时，系统会自动选择当前未使用的词条类型

### 7.2 搜索算法原理

系统采用 **DFS 深度优先搜索 + 剪枝优化** 来穷举所有可能的穿搭组合：

**Step 1：构建候选池**
- 为每个槽位（8个）筛选出可用装备
- 武器槽位按流派规则过滤
- 只考虑适用当前流派的装备

**Step 2：预处理词条**
- 对每件装备，提取其所有可统计词条（主词条 + 副词条）
- 记录每种词条的出现条数和数值总和

**Step 3：DFS 遍历**
- 按 武器1 → 武器2 → 环 → 佩 → 冠胄 → 胸甲 → 胫甲 → 腕甲 的顺序遍历
- 每个槽位尝试所有候选装备
- 实时维护当前已选装备的词条统计（条数 + 数值总和）

**Step 4：剪枝优化**
- 在遍历过程中，如果发现即使把剩余所有槽位都填满目标词条，也无法满足某个条件，则**提前剪枝**，跳过该分支
- 大幅减少无效计算

**Step 5：结果收集**
- 当 8 个槽位全部填满且满足所有条件时，记录该方案
- 最多收集 **15 套**方案后停止搜索

### 7.3 搜索结果展示

搜索完成后，以卡片形式展示符合条件的方案：

- **分页浏览**：用"上一套 / 下一套"按钮在结果间切换
- **8 槽位装备清单**：显示每个槽位穿戴的装备名称
- **词条统计**：显示该方案的全部词条（名称、条数、数值总和）
- **条件达成情况**：显示每个搜索条件的实际达成条数

**载入方案：**
点击"载入当前搭配"，可一键将该方案的 8 槽位填充到主界面的穿搭区域中。

### 7.4 搜索范围说明

- **只统计主词条和副词条**
- **不统计定音词条**
- 按当前流派的双武器规则自动穷举合法方案
- 如果装备库中某部位没有可用装备，该部位视为"空"

## 八、词条汇总复制与联动

### 8.1 复制词条汇总

点击"复制词条汇总"按钮，将当前方案的完整信息以 JSON 格式复制到剪贴板。

**复制内容格式：**
```json
{
  "account": "角色名",
  "className": "破竹·尘",
  "schemeName": "首领输出方案",
  "slots": { ... },
  "totals": { "精准率": 47.5, "会心率": 38.2, ... },
  "counts": { "精准率": 8, "会心率": 6, ... }
}
```

### 8.2 写入毕业率缓存

点击"写入毕业率缓存"按钮，将当前搭配的数据写入本地 `localStorage`，供毕业率计算器读取。

**缓存键名：** `yysls_outfitter_export_v1`

**缓存内容：**
```json
{
  "account": "角色名",
  "className": "破竹·尘",
  "schemeName": "首领输出方案",
  "slots": { ... },
  "aggregates": { ... },
  "exportedAt": "2026-05-10T15:30:00.000Z"
}
```

**使用流程：**
1. 在搭配器中组好方案，点击"写入毕业率缓存"
2. 切换到毕业率计算器页面
3. 计算器会自动读取缓存中的数据，无需重复录入

## 九、数据存储说明

### 9.1 存储键名

装备搭配器使用以下 `localStorage` 键：

| 键名 | 说明 |
|------|------|
| `yysls_armory_import_data_v2` | 装备管理器的原始数据（搭配器只读） |
| `yysls_armory_selected_account_v2` | 装备管理器当前选中的角色（搭配器只读） |
| `yysls_outfitter_export_v1` | 搭配器写入毕业率缓存的数据 |
| `game_outfitter_data_{角色名}` | 每个角色的搭配方案存储 |

### 9.2 数据安全

- 所有操作纯前端完成，**不上传服务器**
- 清除浏览器缓存会导致数据丢失
- **强烈建议定期导出备份**

## 十、使用流程示例

### 场景一：刚整理完装备，想快速组一套完整配装

1. **在装备管理器中录入装备**
   - 录入各部位的装备
   - 补全主词条、定音词条、副词条
   - 标记适用流派

2. **进入装备搭配器**
   - 切换角色
   - 切换流派
   - 页面自动读取该角色的装备库

3. **手动配装**
   - 依次点击 8 个槽位
   - 从候选列表中选择装备放入
   - 右侧词条汇总实时更新

4. **保存方案**
   - 给当前搭配命名
   - 点击"保存方案"
   - 后续可随时切换回来

### 场景二：按词条目标反推穿搭组合

1. **进入词条条数搜索面板**
2. **添加搜索条件**
   - 条件1：会心率 ≥ 8 条
   - 条件2：精准率 ≥ 3 条
3. **点击"开始搜索"**
4. **浏览搜索结果**
   - 用"上一套 / 下一套"切换
   - 查看每套方案的装备清单和词条统计
5. **点击"载入当前搭配"**
   - 自动填充到 8 槽位
6. **保存方案**

### 场景三：组完配装后继续算毕业率

1. **在搭配器中完成配装**
2. **点击"写入毕业率缓存"**
3. **切换到毕业率计算器**
   - 计算器自动读取缓存数据
   - 直接进行数值试算

## 十一、常见问题

### Q1：为什么候选装备列表是空的？

- 装备管理器中没有录入装备
- 当前角色在装备管理器中没有数据
- 当前流派的武器类型在装备库中不存在

**解决方法：** 先前往装备管理器录入装备，确保选择了正确的角色和流派。

### Q2：词条搜索为什么找不到结果？

- 目标条数设置过高，装备库中无法满足
- 某些部位没有可用装备
- 尝试降低条数要求，或减少搜索条件数量

### Q3：切换流派后武器槽位为什么被清空了？

这是正常行为。切换流派时，如果已装备的武器类型不符合新流派的规则，系统会自动清空武器槽位，避免出现非法组合。

### Q4：搭配器的数据会丢失吗？

会的。所有数据保存在浏览器 `localStorage` 中，清除浏览器缓存或更换设备会导致数据丢失。**建议定期在装备管理器中导出备份。**

### Q5：词条搜索的结果最多只有 15 套吗？

是的。系统最多展示 15 套符合条件的方案。如果装备库很大，可能存在更多合法组合，但为了避免渲染压力和决策困难，系统限制为 15 套。

### Q6：词条搜索统计定音词条吗？

**不统计。** 词条搜索只统计主词条和副词条，不统计定音词条。这是因为定音词条通常追求特定类型，不适合用"条数"来衡量。

### Q7：同一角色可以保存多少套方案？

理论上没有硬性限制（受限于浏览器存储空间）。但建议保持在合理数量（如 10 套以内），方便管理和切换。

## 十二、术语表

| 术语 | 解释 |
|------|------|
| **装备管理器** | 用于录入和管理单件装备的工具（`/tools/yysls-armory/`） |
| **装备搭配器** | 用于组合成套配装方案的工具（`/tools/yysls-outfitter/`） |
| **毕业率计算器** | 用于计算当前配装毕业率的工具（`/tools/yysls-graduation/` 或 `/tools/yysls-tiaolv/`） |
| **承音** | 装备词条达到理论最大值的 94% 或 100% |
| **主词条** | 装备上固定的一条主要词条 |
| **副词条** | 装备上随机生成的 1-4 条次要词条 |
| **定音词条** | 通过定音石洗出的额外词条 |
| **DFS** | 深度优先搜索，词条搜索使用的核心算法 |
| **剪枝** | 在搜索过程中提前排除不可能满足条件的分支，提升效率 |
| **localStorage** | 浏览器本地存储，所有数据的保存位置 |

## 十三、一句话总结

> 装备搭配器是连接"装备管理"和"毕业率计算"的桥梁：
> - 从装备管理器读取单件装备
> - 按流派规则组合成完整 8 槽位方案
> - 自动汇总词条统计
> - 支持按目标词条反推穿搭
> - 保存多套方案供切换
