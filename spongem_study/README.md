# yysls.leoq7.com 功能分析

> 本文档是对 https://yysls.leoq7.com/ （燕云十六声装备毕业率管理器）的前端功能拆解与分析，用于学习和参考其产品设计与交互组织方式。

---

## 一、产品定位

**燕云十六声装备毕业率管理器** 是一款围绕《燕云十六声》打造的纯前端单页工具，核心定位是：

- **装备库管理**：录入、保存、筛选单件装备
- **面板方案模拟**：按流派组合 8 槽位装备，实时计算面板属性
- **毕业率分析**：基于 Excel 表格公式计算毕业率、秒伤、词条收益等
- **OCR 批量录入**：通过截图识别快速导入装备词条

一句话概括：**装备管理 + 面板模拟 + 毕业率计算 + OCR 导入** 的四合一工具。

---

## 二、核心功能模块

### 1. 角色管理

页面顶部提供角色切换与管理：

- **新建角色**：输入角色名称创建独立数据空间
- **删除角色**：移除当前选中的角色及其所有装备数据
- **角色切换**：不同角色之间的装备库完全隔离
- **首次进入引导**：无角色时显示欢迎提示，引导用户创建角色

### 2. 装备录入与编辑

点击"录入装备"弹出模态框，支持完整录入一件装备的所有信息：

**基础信息**：
- 装备位置（武器 / 环 / 佩 / 冠胄 / 胸甲 / 胫甲 / 腕甲）
- 武器种类（仅在位置为武器时出现：剑、枪、伞、扇、绳镖、双刀、陌刀、横刀、拳甲、舞绫鼓）
- 承音标记（checkbox）
- 紫装标记（checkbox）
- 装备名称（自定义备注名）

**可用流派限制**：
- 多选下拉框，限制该装备适用的流派
- 默认"全部流派"

**词条录入**：
- 主词条：类型下拉 + 数值输入 + 单位自动切换（% 或固定值）+ 品质标签
- 副词条：支持多条（从 HTML 结构看至少支持 4 条），每条独立选择类型和数值
- 定音词条：类型下拉 + 数值输入
- 数值输入框旁有"↑"按钮（推测为快捷填入该词条类型上限值）

**转律冷却**：
- 提供"进入转律冷却"按钮
- 记录后冷却 7×24 小时
- 可在毕业率分析的"转律 CD 提醒"标签页查看

**OCR 辅助录入**：
- 装备录入弹窗底部有"📷 文字识别"按钮
- 支持上传图片或 Ctrl+V 粘贴截图
- 使用 Tesseract.js 在浏览器端完成 OCR 识别
- 识别结果需手动校验和调整

### 3. 装备库展示与筛选

**筛选栏**：
- 部位胶囊按钮（全部 / 武器 / 环 / 佩 / 冠胄 / 胸甲 / 胫甲 / 腕甲）
- 点击筛选后只显示对应部位的装备

**装备卡片**：
- 网格布局展示所有装备
- 每张卡片显示装备的核心信息（名称、部位、词条摘要等）
- 空状态时显示引导文案

### 4. 面板与方案系统

页面右侧为固定的面板区域，采用可折叠设计：

**头部控制区**：
- 流派选择下拉框
- 表格版本选择下拉框（不同流派对应不同的 Excel 计算表）
- 武库选择下拉框

**方案管理**：
- 方案选择下拉框
- 修改方案名按钮（✎）
- 删除方案按钮（🗑）
- 新增方案按钮（+ 新增）

**心法区域**：
- 4 个心法槽位，每个槽位显示心法图标和名称
- 点击可弹出心法选择弹窗，更换心法

**8 槽位装备搭配**：
- 武器1、武器2、冠胄、胸甲、环、佩、胫甲、腕甲
- 点击已装备的槽位可卸下装备
- 空槽位显示占位文字

**弓诀与套装**：
- 弓诀选择：精准弓 / 会心弓 / 会意弓
- 套装选择下拉框

**面板选项**：
- 提前获得下半赛季属性（毕业率将虚高）
- 首领视为玩家
- 贷款满定音
- "面板不对？"提示入口

### 5. 毕业率分析（核心功能）

点击毕业率横幅或"›"箭头，打开毕业率分析大弹窗：

**左侧信息栏**（可展开/收起）：
- 当前毕业率大数字展示
- Excel 表格显示对比值
- 数据库更新时间、版本号、表格作者
- 当前配装装备列表

**右侧标签页**（7 个功能标签）：

| 标签 | 功能 |
|------|------|
| 手动填写表格 | 模拟 Excel 计算表的输入界面，手动填写各项参数 |
| 最佳配装 | 功能开发中 |
| 词条优先级 | 分两部分：①当前配装基础上新增词条的收益排序 ②扣除某词条会损失的排序 |
| 培养建议 | 针对当前配装给出具体的培养方向建议 |
| 转律建议 | 选择左侧装备部位后，分析该部位转律的收益和方向 |
| 单件装备对比 | 选择某部位后，列出该部位所有候选装备，对比替换收益。支持"冻结当前定音"和"假设满承音"两种对比模式 |
| 转律 CD 提醒 | 显示所有进入转律冷却的装备及剩余冷却时间 |

**毕业率实时计算**：
- 基于 `excel-runtime.js` 在浏览器端运行 Excel 公式
- 数据来源为 `generated-calc-strings.js` 和 `generated-calc-metadata.js`
- 计算结果包括：毕业率百分比、Excel 表格显示值、轴期望秒伤

### 6. 批量 OCR 导入

页面顶部提供"批量 OCR"按钮，打开独立弹窗：

**功能说明**：
- 借助外部 PC 端工具，从游戏背包界面、培养界面或他人方案界面批量截图 OCR
- 识别全部装备词条并快速导入

**使用流程**：
1. 下载外部工具（百度网盘，支持带鱼屏）
2. 以管理员模式运行外部工具
3. 在游戏中批量截图识别
4. 复制识别结果文本
5. 在弹窗中选择目标流派
6. 粘贴 OCR 识别结果
7. 确认识别后进入结果预览
8. 可选择保存到当前角色或新建角色保存

**识别结果预览**：
- 网格展示所有识别出的装备卡片
- 每张卡片可预览和编辑
- 底部提供保存选项

### 7. 数据导入导出

页面顶部提供"导出/导入数据"按钮：

**导出**：
- 点击"导出数据"按钮生成文本格式的装备数据
- 支持"下载为文件"保存到本地

**导入**：
- 上传 `.txt` 文件导入
- 直接粘贴数据文本导入
- 导入前显示警告：将完全覆盖当前角色的所有装备数据
- 需二次确认后才执行覆盖

### 8. 装备详情浮窗

在毕业率分析的单件对比等场景中，点击装备可弹出浮动详情窗口：
- 显示该装备的完整信息（名称、部位、所有词条、承音/紫装状态等）
- 独立于模态框的浮动层设计，便于快速查看

## 三、技术特点

| 技术点 | 说明 |
|--------|------|
| 纯前端 | 无后端服务器，所有数据存在浏览器本地 |
| Excel 公式移植 | 通过 `excel-runtime.js` 在浏览器端运行原始 Excel 计算逻辑 |
| 数据分离 | 计算字符串、元数据、运行时分别拆分为独立 JS 文件，便于更新表格版本 |
| OCR 本地处理 | 引入 Tesseract.js，图片识别在浏览器端完成，不上传服务器 |
| 批量 OCR 外部化 | 复杂的屏幕截图逻辑通过外部 PC 工具完成，工具只负责结果解析和导入 |
| 单页应用 | 所有功能在一个页面内通过模态框和折叠面板组织，无页面跳转 |

## 五、值得借鉴的设计

1. **毕业率分析的模块化标签页**：将毕业率相关的 7 个功能统一组织在一个大弹窗中，通过标签切换，信息密度高但不杂乱。

2. **单件装备对比的对比模式**："冻结当前定音"和"假设满承音"两种对比维度，覆盖了玩家最关心的两种假设场景。

3. **OCR 与外部工具的分工**：浏览器端只做图片识别（Tesseract.js），复杂的屏幕区域截图由外部 PC 工具完成，各自发挥所长。

4. **Excel 运行时分离**：将计算逻辑、数据字符串、元数据拆成三个独立 JS 文件，更新表格版本时只需替换对应文件。

5. **转律 CD 的系统化记录**：不仅记录冷却，还在毕业率分析中给出转律建议，形成"记录 → 提醒 → 建议"的闭环。
