## 一、产品概述

**调率器**是本站围绕《燕云十六声》打造的一款**纯前端综合工具页**，集装备管理、面板模拟、毕业率计算、调率对比、OCR 录入于一体。

它的核心定位是：**在一个页面内完成从"装备录入"到"毕业率分析"的完整闭环**，并为频繁调率操作做了专门优化：

- 破竹鸢的核心毕业率计算使用专用前端计算模块（将 Excel 工作簿公式转译为 JavaScript），计算速度快
- 已计算过的方案会在本地复用结果，再次查看和连续筛选时响应更快
- 使用独立的本地缓存，不影响站内其他工具的数据

### 适合什么场景使用

| 场景 | 建议使用方式 |
|------|-------------|
| 刚获得新装备，想录入并看面板变化 | 直接录入 → 装备上架面板 → 观察毕业率 |
| 想知道"换某件装备有没有收益" | 使用毕业率分析 → 单件装备对比 |
| 想知道"下一培养方向是什么" | 使用毕业率分析 → 词条优先级 / 培养建议 |
| 大量装备需要快速入库 | 使用批量 OCR 导入 |
| 换了设备或浏览器，需要迁移数据 | 使用导出/导入数据功能 |
| 想模拟"满承音后"的强度 | 使用对比功能中的"假设满承音"开关 |

## 二、快速上手

### 第一步：创建角色

打开调率器页面后，如果还没有角色，页面会显示欢迎提示：

> "请点击右上角 **+ 新建角色** 按钮创建新角色"

点击页面右上角的 **"+ 新建角色"**，输入角色名称后确认创建。每个角色的装备数据完全独立。

### 第二步：录入装备

点击 **"录入装备"** 按钮，填写装备信息（详见第四章），保存后装备会出现在左侧装备库中。

### 第三步：上架到面板

点击面板右侧的 8 个槽位之一，从装备库中选择装备放入。放入后，面板会自动汇总词条并计算毕业率。

### 第四步：查看毕业率

页面右侧会实时显示当前毕业率、轴期望秒伤等核心数据。点击毕业率横幅可进入更详细的分析界面。

## 三、角色管理

### 1. 创建角色

- 点击页面右上角 **"+ 新建角色"** 按钮
- 在弹出的模态框中输入角色名称（必填）
- 点击 **"确认创建"**
- 新角色自动成为当前选中角色

### 2. 切换角色

- 点击 **"当前角色"** 下拉框
- 选择要切换的角色名称
- 页面会立即加载该角色的装备库和方案数据

### 3. 删除角色

- 在角色下拉框中选中要删除的角色
- 点击角色下拉框右侧的 **"删除"** 按钮
- **注意：删除后该角色的所有装备和方案将不可恢复，请提前导出备份**

## 四、装备录入与编辑

### 1. 打开录入界面

点击页面左上角的 **"录入装备"** 按钮，或点击已有装备的编辑按钮，会弹出装备录入/编辑模态框。

### 2. 基础信息

| 字段 | 说明 |
|------|------|
| **装备位置** | 必填。可选：武器、环、佩、冠胄、胸甲、胫甲、腕甲 |
| **武器种类** | 仅当位置为"武器"时显示。可选：剑、枪、伞、扇、绳镖、双刀、陌刀、横刀、拳甲、舞绫鼓 |
| **承音** | 勾选标记该装备已承音（影响基础面板） |
| **紫装** | 勾选标记该装备为紫色品质（部分部位会扣减外功攻击面板） |
| **装备名称** | 必填。自定义备注名，用于在装备库中识别 |

### 3. 可用流派限制（多选）

- 默认"全部流派（默认）"，表示该装备适用于所有流派
- 点击下拉区域可展开多选框，勾选该装备适用的具体流派
- 流派选择影响后续在面板中该装备是否可被选用

当前支持的 10 个分支流派：

- 鸣金·虹（剑 + 枪）
- 鸣金·影（剑 + 枪）
- 裂石·威（陌刀 + 枪）
- 裂石·钧（唐横刀 + 陌刀）
- 牵丝·玉（伞 + 扇）
- 牵丝·霖（伞 + 扇）
- 牵丝·翊（舞绫鼓 + 扇）
- 破竹·风（双刀 + 绳镖）
- 破竹·尘（伞 + 绳镖）
- 破竹·鸢（拳甲 + 绳镖）

### 4. 主词条

- **类型**：下拉选择词条类型（劲、敏、势、最小外功攻击、最大外功攻击、精准率、会心率、会意率等）
- **数值**：输入具体数值
  - 百分比类词条（如精准率）输入框旁会自动显示 `%` 符号
  - 固定值类词条（如劲）不显示 `%`
- **快捷填入**：数值输入框旁有 `↑` 按钮，点击可快捷填入该词条类型的上限值（用于快速试算）
- **品质标签**：输入数值后，会根据数值范围自动显示品质标签（如极品、上品等）

### 5. 副词条

- 固定维护 **4 个副词条位置**
- 每个副词条独立选择类型和数值
- 支持清空某个副词条位置（置空）
- 词条类型和单位切换逻辑与主词条相同

### 6. 定音词条

- 仅一条，类型和数值的录入方式与主词条相同
- 定音词条在部分对比场景中可以"冻结"，用于只对比其他变量

### 7. 转律冷却

- 编辑已有装备时，模态框底部会出现 **"进入转律冷却"** 按钮
- 点击后记录当前时间，该装备进入 7×24 小时的转律冷却期
- 可在毕业率分析的 **"转律 CD 提醒"** 标签页查看所有冷却中的装备及剩余时间

### 8. 保存与取消

- 点击 **"保存装备"** 保存当前录入/修改的内容
- 点击 **"取消"** 关闭模态框，不保存修改
- 编辑已有装备时，所有修改会自动生效

## 五、装备库展示与筛选

### 1. 筛选栏

装备库顶部有一排胶囊按钮，用于快速筛选：

- **全部**：显示当前角色所有装备
- **武器 / 环 / 佩 / 冠胄 / 胸甲 / 胫甲 / 腕甲**：只显示对应部位的装备

### 2. 装备卡片

每件装备以卡片形式展示在网格中，卡片上显示：

- 装备名称
- 部位图标/文字
- 武器类型（如果是武器）
- 承音/紫装标记
- 主词条摘要（类型 + 数值）
- 定音词条摘要
- 副词条摘要（前几条）

### 3. 编辑与删除装备

- 点击装备卡片上的 **"编辑装备"** 按钮，打开编辑模态框
- 在编辑弹层中可以修改所有信息
- 编辑弹层中支持 **删除整件装备**

### 4. 空状态

当当前筛选条件下没有装备时，显示提示：

> "当前数据库无装备，请点击右上角 **录入装备** 按钮进行装备录入。"

## 六、面板与方案系统

页面右侧为固定面板区域，采用可折叠设计。点击面板标题栏可展开/收起。

### 1. 面板头部控制区

| 控件 | 说明 |
|------|------|
| **流派** | 下拉选择当前模拟的流派。当前以破竹体系为主 |
| **表格** | 选择使用的 Excel 计算表版本（不同流派对应不同表格） |
| **武库** | 选择武库等级/类型，影响基础面板计算 |

### 2. 方案管理

方案是"一整套 8 槽位装备 + 心法 + 弓诀 + 套装"的组合。

| 操作 | 说明 |
|------|------|
| **切换方案** | 在"方案"下拉框中选择已保存的方案 |
| **修改方案名** | 点击 `✎` 按钮，修改当前方案名称 |
| **删除方案** | 点击 `🗑` 按钮，删除当前方案（不删除装备） |
| **新增方案** | 点击 **"+ 新增"** 按钮，创建空白方案 |

### 3. 心法区域

- 面板显示 4 个心法槽位，每个槽位显示心法图标和名称
- 点击心法槽位，弹出 **"更换心法"** 模态框
- 在心法选择网格中点击某个心法，即可装备到对应槽位

### 4. 八槽位装备搭配

8 个装备槽位的对应关系：

| 槽位 | 显示名称 | 说明 |
|------|----------|------|
| weapon1 | 武器1 | 流派对应的第一把武器 |
| weapon2 | 武器2 | 流派对应的第二把武器 |
| head | 冠胄 | 头部防具 |
| chest | 胸甲 | 胸部防具 |
| ring | 环 | 首饰 |
| pendant | 佩 | 首饰 |
| legs | 胫甲 | 腿部防具 |
| hands | 腕甲 | 手部防具 |

**操作方式**：

- 点击空槽位：从左侧装备库中筛选出该部位可用装备，点击即可放入
- 点击已有装备的槽位：卸下该装备（槽位变空）

**流派武器限制**：

选定流派后，武器1和武器2槽位只能放置该流派对应的武器类型。例如：

- 破竹·鸢：武器1只能放拳甲，武器2只能放绳镖
- 破竹·尘：武器1只能放伞，武器2只能放绳镖

### 5. 弓诀与套装

| 控件 | 说明 |
|------|------|
| **弓诀** | 三选一：精准弓 / 会心弓 / 会意弓，影响面板计算 |
| **套装** | 下拉选择当前穿戴的套装效果 |

### 6. 毕业率横幅

面板下方有一个醒目的毕业率横幅，显示：

- **当前毕业率**：基于当前面板装备计算出的毕业率百分比
- **Excel 表格显示**：与原始 Excel 表格计算结果的对照值
- **轴期望秒伤**：当前方案的期望 DPS

点击该横幅（或右侧的 `›` 箭头），打开 **毕业率分析** 大模态框。

## 七、毕业率分析

毕业率分析是调率器的核心功能区域，以一个大模态框的形式呈现，分为左右两大区域。

### 1. 左侧信息栏（可展开/收起）

点击 `‹` 切换按钮可展开或收起左侧面板。

**包含信息**：

- **当前毕业率**：大数字展示当前方案的毕业率
- **Excel 表格显示**：与原始工作簿计算结果的对照
- **元信息**：
  - 数据库更新时间
  - 表格版本号
  - 表格作者
- **当前配装装备列表**：列出当前方案中 8 个槽位分别装备的装备名称

**装备选择**：点击左侧列表中的装备，可在右侧"单件装备对比"和"转律建议"标签页中针对该部位进行分析。

### 2. 右侧标签页（七大功能）

#### 标签一：手动填写表格

- 模拟原始 Excel 计算表的输入界面
- 可手动填写各项参数（战斗环境、目标选择、心法开关、外功参数、双暴与增伤参数等）
- 适合高级用户直接修改底层计算参数，绕过装备面板自动汇总
- 修改后实时重新计算毕业率和 DPS

#### 标签二：最佳配装

- **功能开发中**
- 计划功能：自动从装备库中推荐毕业率最高的装备组合

#### 标签三：词条优先级

展示两个维度的词条收益分析：

**左侧：增益排序（红色标题）**
- "在当前配装的基础上，再新增的词条收益"
- 列出各类词条如果新增一条，对毕业率/DPS 的提升幅度
- 按收益从高到低排序
- **用途**：指导"下一件装备该追求什么词条"

**右侧：损失排序（绿色标题）**
- "在当前配装的基础上，扣除某词条会损失"
- 列出当前配装中已有的各类词条，如果去掉一条会损失多少
- 按损失从大到小排序
- **用途**：指导"当前哪些词条最不能丢"

#### 标签四：培养建议

- 针对当前配装给出具体的培养方向建议
- 分析当前装备的提升空间和优先级
- 内容根据当前流派和配装动态生成

#### 标签五：转律建议

- 需要先点击左侧信息栏中的某件装备，选择分析部位
- 针对该部位给出转律（洗词条）的方向建议
- 分析保留哪些词条、替换哪些词条收益最大

#### 标签六：单件装备对比

**核心调率功能之一**。

使用前需先点击左侧信息栏中的装备，选择要对比的部位。

**对比控制选项**：

| 开关 | 说明 |
|------|------|
| **冻结当前定音** | 对比时保留当前装备的定音词条不变，只替换其他词条。用于"只换装备不换定音"的场景 |
| **假设满承音** | 将对比装备的所有数值拉满至 94%（承音上限）。用于"这件装备养满后有多强"的预估 |

**对比列表**：

- 列出该部位装备库中所有候选装备
- 每件候选装备显示：
  - 装备名称和核心词条
  - 替换后的预计毕业率变化
  - 预计 DPS 变化
- 点击某件装备可直接将其替换到当前方案中

**装备详情浮窗**：点击对比列表中的装备，可弹出浮动详情窗口，查看该装备的完整词条信息。

#### 标签七：转律 CD 提醒

- 列出所有已进入转律冷却的装备
- 显示每件装备的：
  - 名称和部位
  - 进入冷却的时间
  - 剩余冷却时间（7×24 小时制）
- 冷却结束后自动从列表中移除

## 八、数据导入与导出

点击页面右上角的 **"导出/导入数据"** 按钮打开数据管理模态框。

### 1. 导出数据

- 点击 **"导出数据"** 按钮
- 页面会将当前角色的所有装备和方案数据以文本格式生成到下方文本框中
- 点击 **"下载为文件"** 可将数据保存为本地 `.txt` 文件

### 2. 导入数据

**方式一：上传文件**
- 点击 **"上传文件导入"**，选择之前导出的 `.txt` 文件
- 文件内容会自动读入文本框

**方式二：粘贴导入**
- 点击 **"粘贴导入"** 按钮（或直接将数据粘贴到文本框）

**确认导入**：
- 文本框中有有效数据后，页面会显示警告提示：
  > "导入数据将完全覆盖当前角色（xxx）的所有装备数据！"
- 点击 **"确认导入"** 执行覆盖导入
- 点击 **"取消"** 放弃导入

**重要提示**：
- 导入会**完全覆盖**当前角色的所有装备数据，不会合并
- 建议导入前先导出当前数据作为备份
- 数据格式为纯文本，可跨设备、跨浏览器迁移

## 九、OCR 文字识别

OCR 功能用于通过截图自动识别装备词条，减少手动录入的工作量。

### 1. 单件 OCR（装备录入弹窗内）

在装备录入/编辑模态框的底部，点击 **"📷 文字识别"** 按钮。

**操作流程**：

1. **准备截图**：在游戏中打开装备详情界面，截图（确保背景干净、文字清晰，尽量不要截图到词条左侧的竖线等干扰元素）
2. **粘贴图片**：
   - 点击 OCR 区域的 **"选择文件上传"** 按钮，从本地选择截图文件
   - 或直接将截图 `Ctrl+V` 粘贴到识别区域
3. **等待识别**：Tesseract.js 在浏览器端进行文字识别，页面会显示进度条
4. **结果填充**：识别完成后，系统会自动尝试将识别结果填充到对应的词条输入框中
5. **手动校验**：**OCR 识别结果可能不准确，务必逐项核对并手动修正**

**识别效果提示**：
- 截图质量直接影响识别准确率
- 建议在装备详情界面截图，避免背景杂乱
- 百分比符号 `%` 和数字 `0`/`O` 容易混淆，需重点检查

### 2. 关闭 OCR 弹窗

点击 OCR 弹窗右上角的 `×` 或点击遮罩层外部区域即可关闭。

## 十、批量 OCR 导入

批量 OCR 适合一次性导入大量装备，需要借助外部 PC 端工具完成截图识别。

### 1. 打开批量 OCR

点击页面右上角的 **"批量 OCR"** 按钮。

### 2. 下载外部工具

- 弹窗中提供外部工具的百度网盘下载链接
- 更新日期和兼容性信息会在链接旁标注（如"支持带鱼屏"）
- 使用前请查看 B 站视频教程了解具体操作流程

### 3. 使用外部工具

1. 下载并解压外部工具
2. **右键以管理员模式运行**（否则可能出现鼠标不动等问题）
3. 确保工具路径下**无任何中文字符（包括中文标点符号）**
4. 在游戏中打开背包界面、培养界面或他人方案界面
5. 运行外部工具进行批量截图和识别
6. 复制外部工具输出的识别结果文本

### 4. 粘贴并导入

1. 在批量 OCR 弹窗中选择 **目标流派**（下拉框选择）
2. 将外部工具的识别结果粘贴到文本框中
3. 点击 **"确认识别"**
4. 系统会解析识别结果，弹出 **"批量 OCR 识别结果"** 预览窗口

### 5. 预览与保存

预览窗口以网格形式展示所有识别出的装备卡片：

- 每张卡片显示装备的核心信息（名称、部位、词条等）
- 可以逐张检查和编辑识别结果
- 底部有两个保存选项：
  - **"保存 OCR 结果到当前角色"**：将装备添加到当前正在使用的角色
  - **"新建角色并保存 OCR 结果"**：创建一个新角色，将装备保存到该角色

**注意事项**：
- 批量 OCR 结果同样可能存在识别误差，建议保存前逐一核对
- 外部工具仅限 PC 端使用
- 如果弹窗报错，请检查路径是否有中文字符

## 十一、面板选项与特殊开关

面板底部有一排复选框选项，用于控制特殊计算规则：

### 1. 提前获得下半赛季属性（毕业率将虚高）

- 勾选后，面板计算会包含下半赛季才开放的属性加成
- **注意**：这会使毕业率显示虚高，仅供提前规划参考，不代表当前真实水平

### 2. 首领视为玩家

- 勾选后，计算目标的伤害公式会按"首领单位视为玩家"处理
- 影响穿透、增伤等属性的实际收益
- 适用于特定 PVP 或特殊副本场景下的模拟

### 3. 贷款满定音

- 勾选后，计算时假设所有装备的定音词条都已达到满值
- 用于"如果我把定音都弄满会有多强"的预估场景
- **注意**：这会使毕业率虚高，仅供目标设定参考

### 4. "面板不对？"提示

点击该文字会弹出提示，说明可能导致面板计算结果与游戏内不一致的常见原因和排查方法。

## 十二、常见问题与注意事项

### 数据安全

- **所有数据保存在浏览器本地（localStorage），不上传任何服务器**
- 清除浏览器缓存、更换浏览器、更换设备都会导致数据丢失
- **建议定期导出数据备份**，尤其是进行大批量操作前

### 流派支持状态

- 当前流派选择以**破竹体系**（破竹·鸢、破竹·尘）为主
- 其他流派的入口保留但暂不开放使用
- 不同流派使用不同的 Excel 计算表，请勿混用

### 计算精度

- 调率器的毕业率计算基于 Excel 工作簿公式的转译
- 极少数情况下，由于浮点数精度或公式边界处理差异，前端计算结果与原始 Excel 表格可能存在微小偏差（通常在 0.01% 以内）
- "Excel 表格显示"字段提供了与原始表格的对照值

### 紫装面板扣减

- 勾选"紫装"标记后，部分部位会自动扣减外功攻击面板：
  - 武器：最小外功攻击 -8，最大外功攻击 -20
  - 环：最小外功攻击 -11
  - 佩：最大外功攻击 -17
- 请确保紫装标记与实际装备品质一致

### 缓存与更新

- 调率器使用独立的本地缓存 key，与站内"毕业率工具"、"装备管理器"、"装备搭配器"的数据不互通
- 如果更新了计算表版本，建议重新计算并保存方案，以确保结果基于最新公式

### 性能提示

- 破竹鸢的毕业率计算使用专用前端模块，速度较快
- 首次计算某个方案时需要完整运算，后续查看同一方案会复用缓存结果
- 装备数量过多时，单件对比和词条优先级分析可能需要短暂等待
