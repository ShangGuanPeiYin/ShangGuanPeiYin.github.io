## 一、概述

**调率站**（又称"装备毕业率管理器"）是一个纯前端运行的《燕云十六声》装备分析与毕业率计算工具。它将"装备录入 → 面板模拟 → 毕业率计算 → 优化建议"整合在一个页面中，所有数据保存在浏览器本地，不上传服务器。

### 核心定位

| 功能模块 | 作用 |
|---------|------|
| 装备录入 | 将你的装备词条录入数据库 |
| 面板模拟器 | 8槽位穿搭 + 心法/弓诀/套装配置 |
| 毕业率计算 | 实时计算当前穿搭的毕业率和期望秒伤 |
| 毕业率分析 | 最佳配装穷举、词条优先级、转律建议、装备对比等 |

### 入口地址

站点部署路径：`/tools/yysls-tiaolv/`

### 1.1 本站新增功能说明

本项目在复刻原调率站核心计算链路的基础上，额外加入了以下功能。它们属于本站定制功能，不是源站 `yysls.leoq7.com` 原生功能。后续如果同步源站代码，需要特别检查这些定制功能是否被覆盖。

| 新增功能 | 位置 | 说明 |
|---------|------|------|
| 最多需要承音筛选 | 毕业率分析 → 最佳配装 | 可限制最佳配装结果中 `(需承音)` 装备的数量，例如 `≤2`、`≤3` |
| 需承音数量展示 | 最佳配装结果 | 每套最佳方案会显示 `需承音：N 件` |
| `(需承音)` 与 `(承音)` 区分 | 最佳配装装备卡片 | 系统生成的承音版显示 `(需承音)`，原本已经承音的装备显示 `(承音)` |
| 最佳方案保留 20 套 | 最佳配装结果 | 精确复核后保留前 20 套方案，可通过左右按钮切换 |
| 装备等级标签 | 装备卡片、穿搭槽位、最佳配装结果 | 装备名称旁显示 `[105]`、`[100]`、`[96]` 等等级标签 |

#### 1.1.1 与源站的主要区别

本站的 WASM 计算器、Excel 运行时、计算元数据和 best40 数据与源站保持一致，毕业率、面板、DPS 等核心结果仍走同一套计算链路。差异主要集中在展示和最佳配装筛选：

| 功能点 | 源站行为 | 本站行为 |
|--------|----------|----------|
| 最佳配装返回数量 | 返回前 10 套 | 返回前 20 套 |
| 承音标识 | 通常统一显示 `(承音)` | 区分 `(承音)` 和 `(需承音)` |
| 承音数量筛选 | 无 | 可限制 `(需承音)` 装备不超过指定数量 |
| 承音数量统计 | 无 | 结果中显示 `需承音：N 件` |
| 装备等级展示 | 不显示等级标签 | 显示 `[105]`、`[100]`、`[96]` 等等级 |

#### 1.1.2 最多需要承音筛选

在 **「最佳配装」** 标签页中，`考虑不同弓箭套装` 旁边有一个下拉选项：

```text
最多需要承音：不限 / ≤0 / ≤1 / ≤2 / ≤3 / ≤4 / ≤5 / ≤6 / ≤7 / ≤8
```

这个选项用于控制最佳配装搜索时允许出现多少件 `(需承音)` 装备。

例如选择 `≤2`：
- 系统会跳过所有需要承音超过 2 件的组合
- 最终返回的是“最多需要 2 件承音”条件下的最优方案
- 不是先算出全部结果再从结果里删除，而是在搜索阶段直接过滤

#### 1.1.3 `(需承音)` 与 `(承音)` 的区别

最佳配装中会出现两种承音标识：

| 标识 | 含义 |
|------|------|
| `(承音)` | 这件装备在你的数据库里本身已经是承音装备 |
| `(需承音)` | 这是系统基于普通装备生成的承音版，表示这件装备需要你后续培养到承音 |

“最多需要承音”筛选只统计 `(需承音)`，不统计已经是 `(承音)` 的装备。

#### 1.1.4 装备等级标签

装备名称旁边会显示等级标签，方便在最佳配装结果里快速判断装备来源和可用程度。例如：

| 标签 | 颜色 |
|------|------|
| `[105]` | 金色 |
| `[100]` | 蓝色 |
| 其他等级，如 `[96]` | 灰色 |

如果装备没有等级字段，默认按 `[105]` 显示。

等级标签会出现在三个位置：
- 左侧装备库卡片
- 右侧已穿戴槽位
- 最佳配装结果中的装备卡片

#### 1.1.5 最佳配装 Top20

源站最佳配装最终保留前 10 套方案，本站改为保留前 20 套。这样可以在毕业率接近时多看一些备选方案，尤其适合用“最多需要承音”筛选后，从多套可实现方案里挑选更容易凑齐的一套。

## 三、角色管理

### 3.1 创建角色

点击右上角 **「+ 新建角色」** 按钮，输入角色名称后确认创建。

- 每个角色的数据**完全独立**，包括装备库、穿搭方案、面板配置等
- 支持创建多个角色，通过顶部下拉框切换
- 切换角色后，页面自动加载该角色的全部数据

### 3.2 删除角色

选中某个角色后，点击角色选择框右侧的 **「删除」** 按钮（红色）。

> ⚠️ 删除操作不可恢复，会清空该角色的所有装备和配置数据。

### 3.3 数据导出与导入

点击 **「导出/导入数据」** 按钮：

**导出方式：**
- **导出数据**：生成文本数据到弹窗内的文本框中，可复制
- **下载为文件**：将数据保存为 `.txt` 文件到本地

**导入方式：**
- **上传文件导入**：选择之前下载的 `.txt` 文件
- **粘贴导入**：将数据文本粘贴到文本框中

> ⚠️ 导入数据会**完全覆盖**当前角色的所有装备数据，操作前请确认。

## 四、装备录入

装备录入是整个系统的数据源头。调率站提供**三种录入方式**。

### 4.1 手动录入

点击左侧装备库区域右上角的 **「录入装备」** 按钮，弹出录入表单。

#### 表单字段详解

| 字段 | 说明 |
|------|------|
| **装备位置** | 下拉选择：武器、环、佩、冠胄、胸甲、胫甲、腕甲 |
| **武器种类** | 仅选择"武器"位置时出现：剑、枪、陌刀、唐横刀、伞、扇、双刀、绳镖、拳甲等 |
| **承音** | 勾选表示该装备为承音装备（词条为满值） |
| **紫装** | 勾选表示该装备为紫色品质 |
| **装备名称** | 自定义名称，建议取容易辨认的名字 |
| **可用流派限制** | 多选，限定该装备适用的流派。默认"全部流派" |
| **主词条** | 选择词条类型 + 输入数值 |
| **副词条** | 最多可添加多条副词条，每条包含类型和数值 |
| **定音词条** | 选择类型 + 输入数值 |

#### 快捷按钮

每个数值输入框右侧有一个 **↑** 按钮，点击可自动填入该词条类型的**理论最大值**（承音值）。

#### 编辑已有装备

在装备库中点击任意装备卡片，即可打开编辑弹窗，修改后保存。

---

### 4.2 单件OCR识别

在手动录入弹窗的底部，有一个 **「📷 文字识别」** 按钮（部分浏览器/设备支持）。

**使用方式：**
1. 点击按钮打开OCR弹窗
2. 按 `Ctrl+V` 粘贴装备截图，或点击上传文件
3. 系统自动识别图片中的文字，提取词条信息
4. 识别结果自动填充到表单中，**需人工核对修正**

**截图建议：**
- 背景干净，文字清晰
- 尽量不要截图到其他UI元素（如词条左侧的竖线）
- OCR结果可能不准确，务必手动检查

---

### 4.3 批量OCR（PC端专用）

点击顶部 **「批量OCR」** 按钮，这是配合外部自动化工具使用的高级功能。

**工作原理：**
- 使用外部工具（鼠标宏/图像识别脚本）在游戏的背包界面、培养界面或他人方案界面自动截图并识别
- 将批量识别结果以特定格式复制粘贴到本工具的输入框中
- 一键导入全部装备

**使用步骤：**
1. 下载外部工具（见弹窗内提供的网盘链接）
2. 在游戏背包界面运行工具，自动截图识别
3. 复制工具的输出结果
4. 在本工具中选择对应流派，粘贴结果
5. 确认识别后，可选择保存到当前角色或新建角色

> 注意：外部工具仅限PC端使用，且需确保路径下无中文字符。

## 六、面板模拟器

右侧的「面板」区域是核心交互区，包含完整的 8 槽位配装系统。

### 6.1 8槽位配装

固定 8 个槽位：

| 槽位 | 名称 | 说明 |
|------|------|------|
| 武器1 | 第一把武器 | 根据流派自动限制可选武器类型 |
| 武器2 | 第二把武器 | 根据流派自动限制可选武器类型 |
| 环 | 首饰 | 戒指部位 |
| 佩 | 首饰 | 佩饰部位 |
| 冠胄 | 防具 | 头部防具 |
| 胸甲 | 防具 | 胸部防具 |
| 胫甲 | 防具 | 腿部防具 |
| 腕甲 | 防具 | 手部防具 |

**操作流程：**
1. 点击某个空槽位（或已有装备的槽位）
2. 左侧装备库会自动**过滤**为该槽位可用的装备
3. 点击装备卡片上的按钮，将装备放入槽位
4. 点击槽位中已装备的装备，可**卸下**该装备

### 6.2 流派选择

面板顶部可选择当前流派：

- `鸣金·虹`：剑 + 枪
- `鸣金·影`：剑 + 枪
- `裂石·威`：陌刀 + 枪
- `裂石·钧`：唐横刀 + 陌刀
- `牵丝·玉`：伞 + 扇
- `牵丝·霖`：伞 + 扇
- `牵丝·翊`：舞绫鼓 + 扇
- `破竹·风`：双刀 + 绳镖
- `破竹·尘`：伞 + 绳镖
- `破竹·鸢`：拳甲 + 绳镖

切换流派后，武器槽位会自动过滤为对应类型的武器。

### 6.3 心法配置

面板中有 4 个心法槽位，点击槽位可打开心法选择弹窗。

- 从心法列表中选择要装备的 4 本心法
- 选择后自动更新面板属性
- 心法图标和名称会显示在槽位上

### 6.4 弓诀选择

面板右下角可选择弓诀类型：
- **精准弓**
- **会心弓**
- **会意弓**

不同弓诀会影响精准率、会心率、会意率等面板属性，进而影响毕业率。

### 6.5 套装选择

弓诀旁边可选择当前穿戴的套装，套装效果会自动计入面板计算。

### 6.6 方案管理

面板支持保存多套穿搭方案：

| 操作 | 说明 |
|------|------|
| **新增** | 创建一个新的空方案 |
| **方案下拉框** | 切换已保存的方案 |
| **修改方案名** | 点击 ✎ 按钮重命名当前方案 |
| **删除方案** | 点击 🗑 按钮删除当前方案 |

### 6.7 面板选项

面板底部有三个复选框：

| 选项 | 说明 |
|------|------|
| **提前获得下半赛季属性** | 勾选后计入下半赛季属性加成（毕业率会虚高） |

| **贷款满定音** | 定音词条按满值计算 |

## 七、毕业率计算

### 7.1 毕业率横幅

面板下方有一个醒目的绿色横幅，实时显示：

- **当前毕业率**：基于当前 8 槽位穿搭 + 心法/弓诀/套装计算得出的毕业率百分比
- **Excel表格显示**：如果手动填写了Excel表格，显示表格中的毕业率（用于对比校验）
- **轴期望秒伤**：当前配置下的理论期望秒伤

点击该横幅即可打开 **「毕业率分析」** 弹窗。

### 7.2 毕业率计算原理

毕业率来源于游戏伤害计算公式与Excel表格的映射：

1. 系统读取当前 8 件装备的所有词条
2. 叠加心法、弓诀、套装的属性加成
3. 根据流派对应的伤害公式（技能轴）计算理论输出
4. 将当前输出与"毕业级输出"对比，得出毕业率百分比

## 八、毕业率分析（核心功能）

点击毕业率横幅后打开的弹窗是调率站最强大的分析工具，包含 **7 个标签页**。

弹窗左侧显示当前毕业率、Excel对比率、版本信息、当前装备列表；右侧为各个分析标签页。

---

### 8.1 手动填写表格

此标签页用于**与Excel毕业率表格联动**。

你可以在网页中直接填写各项属性数值，系统会实时计算毕业率，并与Excel表格的结果进行对比验证。

**用途：**
- 验证网页计算与Excel计算是否一致
- 快速调整某项属性看对毕业率的影响
- 作为Excel的"网页版快捷入口"

---

### 8.2 最佳配装 ⭐（核心算法）

这是调率站最复杂、最强大的功能。它会**遍历你数据库中所有可能的装备组合**，找出毕业率最高的穿搭方案。

#### 8.2.1 算法原理

**Step 1：装备预处理**

系统首先对数据库中的每件装备进行"承音化处理"：

| 装备平均词条占比 | 处理方式 |
|-----------------|---------|
| < 92% | 只保留承音版（所有词条拉满到理论最大值） |
| 92% ~ 96% | 同时保留原始版 + 承音版，两种都参与遍历 |
| ≥ 96% | 词条已接近完美，只保留原始版 |

**Step 2：流派过滤**

- 仅保留当前流派可用的装备
- 武器1、武器2 严格匹配流派武器规则
- 根据"可用流派限制"字段过滤

**Step 3：定音策略**

遍历过程中，**所有定音词条统一按满值计算**（即"贷款满定音"）。这是基于"最终定音一定能洗满"的假设。

**Step 4：组合穷举**

使用生成器（Generator）+ 栈结构，以深度优先的方式遍历所有可能的 8 槽位组合：

```
武器1选择数 × 武器2选择数 × 环选择数 × 佩选择数 × 
冠胄选择数 × 胸甲选择数 × 胫甲选择数 × 腕甲选择数
```

如果勾选了"考虑不同弓箭套装"，则上述结果再 × 3（精准弓/会心弓/会意弓）。

**Step 5：Top 200 快速筛选**

由于组合数可能非常庞大（几十万甚至上千万），系统采用**两步计算策略**：

1. **快速计算**：使用轻量级算法估算每套组合的毕业率
2. 维护一个容量为 **200** 的优先队列，只保留毕业率最高的 200 套方案
3. 遍历过程中实时更新进度条

**Step 6：Excel 精确复核**

对 Top 200 方案使用完整的 Excel 运行时进行**精确计算**，最终返回毕业率最高的 **Top 20** 方案。

#### 8.2.2 高级设置

**面板高级设置**

点击「面板高级设置」按钮，可以设置属性范围过滤条件：

| 过滤项 | 说明 |
|--------|------|
| 最小外功攻击 | 设定外功攻击下限/上限 |
| 最大外功攻击 | 设定外功攻击上限 |
| 精准率 | 设定精准率范围 |
| 会心率 | 设定会心率范围 |
| 会意率 | 设定会意率范围 |

所有不满足条件的组合会在快速计算阶段被直接丢弃。

**考虑不同弓箭套装**

勾选后，系统会同时遍历三种弓诀，找出全局最优解。

**最多需要承音**

这是本站新增的筛选项，用来限制最佳方案里 `(需承音)` 装备的数量。

| 选项 | 含义 |
|------|------|
| 不限 | 不限制需要承音的装备数量 |
| ≤0 | 只允许不需要额外承音的方案 |
| ≤1 ~ ≤8 | 最多允许对应数量的 `(需承音)` 装备 |

该限制会在组合搜索阶段生效。选择 `≤2` 时，系统会直接跳过所有需要承音超过 2 件的组合，然后在剩余组合中寻找毕业率最高的方案。

#### 8.2.3 指定转律目标（定向优化）

这是最佳配装最具特色的功能。

**使用方式：**
1. 点击「指定转律目标」卡片
2. 从装备库中选择某件装备
3. 选择该装备的一条副词条
4. 确认后，该部位将锁定为这件装备，但会遍历该词条**所有可能的转律结果**

**原理：**
- 系统获取该副词条对应的全武库转律池
- 生成该词条转律为每一种可能词条的"装备变体"
- 这些变体与数据库中其他装备一起参与穷举
- 最终告诉你：**把这条副词条转律成什么，能让整体毕业率最高**

**示例：**
> 你有一件腕甲，副词条包含【劲】。你想知道把【劲】转律成什么最好。
> 
> 系统会生成：该腕甲的【劲】→ 精准率、该腕甲的【劲】→ 会心率、该腕甲的【劲】→ 最小外功攻击……等所有变体。
> 
> 最终结果显示：转律为"精准率"时，整体毕业率达到最高 87.32%。

#### 8.2.4 结果解读

计算完成后，页面显示 Top20 最佳方案：

- **方案编号**：1 / 20 等，可用 `<` `>` 切换
- **毕业率**：精确到小数点后两位
- **轴期望秒伤**：该方案的理论输出
- **DPS**：每秒伤害
- **弓诀类型**：该方案使用的弓诀
- **需承音数量**：显示该方案中 `(需承音)` 装备的数量
- **8槽位装备清单**：每件装备的名称
- **转律方案**：如果有指定转律目标，显示建议的转律操作

右侧会弹出**浮动面板**，显示该方案的完整最终面板属性（攻击、精准率、会心率、穿透、增伤等）。

点击 **「使用该方案」** 可将其一键应用到主界面的面板模拟器中。

### 8.3 词条优先级

此标签页分析**在当前配装基础上，新增或扣除某词条的收益**。

分为两个面板：

#### 8.3.1 新增词条收益（红色标题）

> "在当前配装的基础上，再新增的词条收益"

系统计算：如果在你身上再增加一条某种词条，毕业率会提升多少。

按收益从高到低排序，帮助你判断：
- 下一件装备应该优先追求什么词条？
- 转律时，哪种词条的收益最高？

#### 8.3.2 扣除词条损失（绿色标题）

> "在当前配装的基础上，扣除某词条会损失"

系统计算：如果把你身上的某种词条去掉一条，毕业率会下降多少。

按损失从大到小排序，帮助你判断：
- 你现在的哪些词条是最核心的？
- 换装备时，哪些词条绝对不能丢？

### 8.5 转律建议

**使用前提：** 需要先在左侧点击某件装备，选择要分析的部位。

转律建议会分析该部位所有可用装备，告诉你：

**对比逻辑：**

- 按毕业率从高到低排列

**用途：**

## 九、数据安全与备份

### 9.1 数据存储

- 所有数据保存在浏览器的 `localStorage` 中
- 纯前端运行，**不上传任何数据到服务器**
- 清除浏览器缓存会导致数据丢失

### 9.2 备份建议

**强烈建议定期导出数据备份**，尤其是：
- 录入大量装备后
- 完成一套满意的配装方案后
- 进行浏览器清理前

**备份方式：**
1. 点击「导出/导入数据」
2. 点击「下载为文件」，保存 `.txt` 文件
3. 建议将文件保存在云盘或其他安全位置

### 9.3 数据迁移

更换设备或浏览器时：
1. 在原设备上导出数据
2. 将数据文件发送到新设备
3. 在新设备上打开调率站，粘贴导入或上传文件

## 十一、常见问题

### Q1：为什么网页显示的毕业率和Excel表格不一样？

可能原因：
- Excel表格版本与网页数据库版本不一致
- 网页中某些面板选项（如"提前获得下半赛季属性"）与Excel设置不同
- 心法、弓诀、套装配置不一致
- 建议核对「手动填写表格」标签页中的各项数值

### Q2：最佳配装计算出来的装备我一件都没有，怎么回事？

最佳配装只遍历你**数据库中已有的装备**。如果结果显示 `(需承音)`，说明这是系统基于你已有装备生成的承音版，代表这件装备需要后续培养到承音。你也可以使用“最多需要承音”筛选，限制这类装备在最佳方案中的数量。

### Q3：为什么OCR识别结果不准确？

OCR依赖图片质量和文字清晰度：
- 确保截图背景干净，不要截到竖线等干扰元素
- 文字尽量清晰无模糊
- 识别后务必人工核对所有数值

### Q4：清除了浏览器缓存，数据还能恢复吗？

**不能**。如果没有提前导出备份，数据将永久丢失。请务必定期导出数据。

### Q5：可以同时在多台设备上使用吗？

可以，但数据不互通。需要通过导出/导入功能手动同步数据。

### Q6："贷款满定音"是什么意思？

指在计算时假设所有定音词条都是满值。这是一种"贷款"逻辑——假设你最终能把定音洗满。如果不勾选，则使用装备实际录入的定音数值。

### Q7：为什么「最佳配装」计算时只考虑承音版？

对于词条平均值较低的装备（<92%），系统认为你最终一定会把它洗成承音，因此直接用承音版参与计算。如果你的装备词条已经很高（≥96%），则会保留原始版。

### Q8：转律建议中的"冻结当前定音"有什么用？

勾选后，系统在计算对比时会保留你当前装备的定音词条不变，只对比副词条和主词条的差异。如果不勾选，系统可能会建议你把定音也一起换掉。

## 十二、术语表

| 术语 | 解释 |
|------|------|
| **毕业率** | 当前配置的理论输出与"毕业级配置"输出的比值，以百分比表示 |
| **承音** | 装备词条达到理论最大值的 94% 或 100% |
| **定音** | 装备上通过定音石洗出的额外词条 |
| **转律** | 改变装备副词条类型的操作，有7天冷却期 |
| **转律副本** | 某一副词条转律后可能变成的所有词条的集合 |
| **武库** | 对应流派的转律词条池，不同流派的武库词条不同 |
| **轴期望秒伤** | 基于当前流派技能轴计算的理论每秒伤害 |
| **词条优先级** | 新增/扣除某词条对毕业率的边际影响 |
| **贷款满定音** | 计算时假设所有定音词条都是满值 |
