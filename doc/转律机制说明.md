# 燕云十六声转律机制说明

> 本文记录转律机制的核心规则，以及调率站对转律功能的支持方式。
>
> 最后更新时间：2026年6月

---

## 一、什么是转律

转律是改变装备**副词条类型**的操作。一件装备最多有 4 条副词条，每次转律选择其中一条，将其类型替换为当前流派武库中的另一种词条。

---

## 二、核心规则

### 2.1 操作单位

每次转律**从 4 条副词条中选 1 条**进行转律，转律后该词条类型变为武库词条池中的随机结果。

### 2.2 转律次数限制

| 装备等级 | 转律次数 | 说明 |
| --- | --- | --- |
| **105 级** | 无限次 | 可反复转律，但每次只能在**已选定的同一条副词条**上继续转，不能换选其他副词条 |
| **100 级** | 仅 1 次 | 转律一次后该装备无法再次转律 |
| **96 级** | 仅 1 次 | 转律一次后该装备无法再次转律 |

### 2.3 冷却期

每次转律操作后进入 **7 天（7×24 小时）冷却**，冷却期内无法再次转律同一件装备。

### 2.3 武库词条池

转律结果来自当前流派对应的**武库**。不同流派的武库词条不同：

| 流派 | 武库词条 |
| --- | --- |
| 鸣金（虹/影） | 最大外功攻击、最大鸣金攻击、会心率、会意率、劲、势 |
| 裂石（威/钧） | 最大外功攻击、最小外功攻击、最大裂石攻击、会心率、劲、敏 |
| 牵丝（玉/霖/翊） | 最大外功攻击、最小外功攻击、最大牵丝攻击、会心率、劲、敏 |
| 破竹（风/尘/鸢） | 最大外功攻击、最小外功攻击、最大破竹攻击、会心率、劲、敏 |

## 三、调率站的转律相关功能

### 3.1 转律 CD 提醒

位置：**毕业率分析 → 转律 CD 提醒**

在装备编辑弹窗底部点击「进入转律冷却」，系统记录当前时间并开始 7 天倒计时。此标签页会列出所有正在冷却的装备，显示剩余时间和预计结束时间，冷却结束后标记为「可再次转律」。

### 3.2 转律建议

位置：**毕业率分析 → 转律建议**

先在左侧装备列表中点击一件装备，系统会：

1. 列出该装备所有副词条
2. 对每条副词条，遍历它能转律成的所有武库词条
3. 计算每种转律结果下的整体毕业率
4. 给出建议：**把哪条副词条转律成什么词条，整体毕业率最高**

### 3.3 最佳配装 — 指定转律目标

位置：**毕业率分析 → 最佳配装 → 指定转律目标**

锁定某件装备的某条副词条后，最佳配装搜索会：

- 对该部位生成「该词条所有可能转律结果」的装备变体
- 这些变体与数据库其他装备一起参与完整穷举
- 最终告诉你：转律成哪种词条，整体配装毕业率最优

---

## 四、术语说明

| 术语 | 解释 |
| --- | --- |
| **武库** | 对应流派的转律词条池，决定了该流派装备副词条能转律成哪些词条 |
| **转律副本** | 某条副词条能转律成的所有词条的集合（即武库中的每种词条） |
| **劲 / 敏 / 势** | 转律池中的五维词条，转律后的数值与普通副词条相同（承音上限 66.8） |
