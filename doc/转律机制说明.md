# 燕云十六声转律机制与调率站使用说明

> 本文统一记录当前确认的游戏转律机制，以及调率站对状态记录、转律建议、最佳配装、方案模拟和备份迁移的支持方式。
>
> 最后更新时间：2026年8月5日

---

## 一、转律是什么

转律是一项只作用于装备**副词条槽位**的能力。

一件符合条件的装备可以指定其中一条真实存在的副词条作为转律槽位。指定完成后，这个槽位可以在合法转律词条之间自由切换，也可以切回装备原来的副词条。装备的主词条不会被转律，其他副词条也不会被改变。

因此需要区分三件事：

1. **装备是否具备转律资格**；
2. **具备资格后，是否已经指定了一个副词条槽位**；
3. **在方案或计算中，这个槽位当前模拟切换成了什么词条**。

调率站分别保存这三层含义，避免把游戏实际状态、计算规划和装备原始数据混在一起。

## 二、当前游戏机制

### 2.1 装备资格

- 只有 **110级装备**可以使用转律。
- 110级承音装备同样可以转律，承音不会取消资格。
- 紫装与普通装备遵守相同资格规则。
- 105级、100级、96级以及缺失等级的旧装备都不能转律，但仍可正常穿戴、计算毕业率和参与普通最佳配装。

调率站不会根据等级自动假定所有110级装备都可转律。装备编辑页还需要明确勾选与“承音”“紫装”并列的**可转律**选项，用来记录这件装备在游戏中已经获得了转律资格。非110级装备不显示该选项。

### 2.2 只能指定一个副词条槽位

- 转律只能作用于副词条，不能选择主词条。
- 一件装备最多指定一个副词条槽位。
- 已经指定后，只能在这个槽位上切换词条，不能在计算中擅自改成另一个槽位。
- 删除该副词条、使槽位失效或取消“可转律”后，已指定状态失效。

### 2.3 可以切换并切回

已转律装备的指定槽位可以：

- 保持或切回原副词条；
- 切换成任一合法的转律库词条。

所以“原词条”始终是合法候选。转律建议和最佳配装不能预设“转了必然更强”，而应把原词条与所有合法目标放在一起比较。

### 2.4 副词条不能重复

转律完成后，同一件装备不能出现两个相同的副词条。例如装备另外一条副词条已经是会心率，就不能再把指定槽位切换成会心率。

主词条不参与这项重复限制。主词条与一个副词条同名是合法的，例如主词条为最大外功攻击，转律后的副词条也可以是最大外功攻击。

### 2.5 转律武库

当前基础武库为：

| 武库 | 词条池 |
| --- | --- |
| 鸣金武库 | 最大外功攻击、最大鸣金攻击、会心率、会意率、劲、势 |
| 裂石武库 | 最大外功攻击、最小外功攻击、最大裂石攻击、会心率、劲、敏 |
| 牵丝武库 | 最大外功攻击、最小外功攻击、最大牵丝攻击、会心率、劲、敏 |
| 破竹武库 | 最大外功攻击、最小外功攻击、最大破竹攻击、会心率、劲、敏 |

转律可以选择**其他流派的转律武库**，并非只能使用当前流派同名武库。调率站会合并全部武库的候选并去重。

流派属性攻击是例外：计算当前流派时只保留与该流派相符的属性攻击。例如破竹流派可以从其他武库获得通用的大外、小外、会心率、会意率、劲、敏、势等候选，但属性攻击只保留最大破竹攻击，不会同时提供最大鸣金、裂石或牵丝攻击。破竹风、破竹尘和破竹鸢都按破竹属性处理。

### 2.6 数值口径

调率站生成转律模拟词条时使用当前计算器的理论承音词条数值，再放入当前流派、心法、套装、弓箭、武库、赛季和高级设置环境中计算。这是用于方案比较的理论口径，不会改写装备库里原词条的实际数值。

贷款定音与转律相互独立：贷款定音只替代装备定音，转律只替换指定副词条。两项功能同时开启时会共同进入最终面板和毕业率计算。

## 三、调率站中的状态模型

### 3.1 用户看到的三种业务状态

| 状态 | 条件 | 页面表现 |
| --- | --- | --- |
| 不可转律 | 非110级，或110级但未勾选“可转律” | 不显示转律徽标；非110级不显示勾选框 |
| 待转律 | 110级并勾选“可转律”，但尚未指定副词条 | 装备卡片显示灰色“待转律” |
| 已转律 | 110级并勾选“可转律”，且指定了一个有效副词条 | 卡片显示“已转律：第N条（词条名）”，对应副词条带箭头 |

从游戏转律过程看，可转律装备内部仍是“未指定槽位／已指定槽位”两状态；“不可转律”是网站额外记录的资格层。

### 3.2 保存内容

- 是否具备资格保存在装备字段 `isTransmutable`。
- 只有已转律装备保存槽位记录：

```json
{
  "state": "active",
  "subStatIndex": 2,
  "modelVersion": 2
}
```

- 待转律不额外保存状态对象；`isTransmutable: true` 且没有合法槽位记录即表示待转律。
- 状态记录只表示“哪个槽位具有切换能力”，不保存该槽位在游戏里此刻切到了哪个目标词条。

### 3.3 编辑与取消

装备编辑弹窗内的转律槽位先作为草稿。只有成功保存装备时才提交槽位记录；点击取消不会修改原记录。

装备卡片按稳定装备ID绑定徽标，同名装备各自读取自己的状态，不会全部绑定到第一件同名装备。

## 四、转律建议

位置：**毕业率分析 → 转律建议**。

### 4.1 待转律装备

系统会分别检查装备的每一个有效副词条槽位。对每个槽位都比较：

- 保留原词条；
- 切换成全部武库中的每一个合法目标。

最终给出最值得指定的槽位、推荐目标、最终毕业率以及相对当前方案的差值。

### 4.2 已转律装备

系统只分析已经指定的那个副词条槽位，不允许算法改换槽位。结果仍包含切回原词条；如果原词条最优，页面会明确建议保持或切回。

### 4.3 计算边界

转律建议只替换当前分析装备，其他七件装备保持不变。计算沿用当前方案的流派、流派版本、心法、套装、弓箭、武库、赛季加成、PVP、贷款定音、专属参数和高级设置，因此建议反映的是“这件装备在当前穿搭里怎么切最好”，不会混入换装收益。

若当前方案本身保存了转律模拟，毕业率分析弹窗会先应用该方案覆盖层，再进行建议计算。

## 五、最佳配装自动考虑转律

位置：**毕业率分析 → 最佳配装 → 转律搜索**。

### 5.1 三种搜索模式

1. **不考虑转律**：所有装备只使用原始词条。
2. **自动优化已转律装备**：只有已经指定副词条槽位的装备可以在该槽位切换；待转律装备保持原词条。
3. **同时规划待转律装备**：除已转律装备外，还会为待转律装备同时选择一个副词条槽位和目标词条。

第三种模式给出的是未来规划，不代表游戏中已经完成转律，也不会自动把待转律装备改成已转律。

搜索模式按角色记住上次选择，但不随装备方案保存。切换模式时，尚未执行搜索的“考虑不同弓箭套装”“忽略可用流派限制”和最大需承音数量等选项会保留。

### 5.2 单件装备候选

每件物理装备建立一个互斥候选组：

- 原始装备；
- 需要时生成的承音模拟形态；
- 各个合法转律变体。

同一套配装只能选择其中一个形态，不能让同一物理装备以原装、需承音或多个转律变体同时占据多个部位。真实承音装备和“需承音”模拟形态都继承原装备的可转律资格与已指定槽位；需承音形态继续计入最大需承音数量限制。

原始装备始终保留，算法可以判断不切换反而更优。

### 5.3 合法候选过滤

搜索生成转律候选时必须同时满足：

- 装备为110级且明确勾选“可转律”；
- 只替换真实存在的副词条；
- 已转律装备只能替换指定槽位；
- 待转律规划只能为一件装备选择一个槽位；
- 目标来自全部武库合并后的合法集合；
- 其他流派属性攻击被过滤，只保留当前流派属性攻击；
- 替换后不能产生两个相同副词条；
- 空槽位或过期状态不生成变体。

### 5.4 Top20与高级设置

最终面板、毕业率和高级设置都使用转律后的词条。词条数量上下限也按最终副词条判断。

Top20以“八件原始装备ID + 各自是否需承音”为基础配装键。转律目标不进入去重键；同一套基础装备的多个转律组合只保留毕业率最高的一种。候选阶段即执行这项去重，避免大量同装备转律变体挤占候选名额，Excel复核后再做一次安全去重并取真正的Top20。

结果会显示：

- 使用转律的装备数量；
- 其中待转律规划的数量；
- 每件装备的“原词条 → 目标词条”；
- 已转律切换或待转律规划标记；
- 汇总操作清单和转律后的最终面板。

## 六、方案转律模拟

点击最佳配装结果中的“使用该方案”时，网站保存八件原装备和一层非破坏性的转律选择，例如：

```json
{
  "equip-id": {
    "subStatIndex": 2,
    "targetStat": "会心率",
    "planned": true
  }
}
```

- 只保存实际选择了目标词条的装备；保持原词条时不写记录。
- `planned: true` 表示这是为待转律装备生成的规划。
- 方案覆盖层不会修改装备库原始副词条、`isTransmutable` 或真实已转律槽位。
- 切换方案后，主页最终面板、毕业率、毕业率分析弹窗和主页词条数量汇总都会按方案覆盖层计算。
- 页面会显示“方案转律模拟”操作清单，区分“已转律切换”和“待转律规划”。

如果装备后来完成转律且指定槽位与规划一致，方案可按已完成切换展示。若装备被删除、取消资格、改成非110级、指定槽位不一致、目标不再合法或副词条引用失效，网站会忽略该条覆盖，安全回退原词条并提示失效装备，不会擅自迁移到其他槽位。

## 七、备份、兼容与历史迁移

- 完整备份继续使用 `schemaVersion: 2`。
- 备份保存装备的 `isTransmutable`、各角色合法的已转律槽位，以及方案中的转律选择。
- 导入时校验装备ID、110级资格、副词条位置、模型版本和方案目标；无效引用不会恢复。
- 旧版没有 `isTransmutable` 的装备，仅在存在合法新模型已转律记录时推断为可转律；其他旧装备默认不可转律。
- 旧的多目标 `targets`、旧 active 状态和第三种状态不会恢复为当前状态。
- 非110级、缺失装备、空副词条或无效槽位的历史状态会被清理。
- 旧方案没有转律覆盖字段时按普通方案加载。

搜索结果和其他可重建缓存不进入备份。

### 7.1 云端备份与多设备同步

转律相关数据（`isTransmutable`、`zhuanlv_status_<account>`、方案 `transmutationSelections`）随完整备份一起进入云备份：

- 登录云备份账号后，本地转律状态会随完整备份自动上传到 Supabase，并在多台设备间保持一致。
- 云备份是“本地优先”模型：本地数据变化后自动上传，云端数据不会自动覆盖本地。
- 多台设备使用同一账号时，若另一台设备更新了转律状态，本机打开页面或切回标签页时会检测到云端已变化，暂停自动上传并弹出冲突提示，由你选择“恢复云端备份”或“以本机数据覆盖”。
- 恢复云端备份时按角色合并恢复，只覆盖同名角色；恢复前会先保存一份“恢复前保护”快照。
- 详细机制见《调率站详细说明书》第七章。

## 八、已经删除或停用的旧功能

### 8.1 转律CD提醒已完全删除

网站不再提供7天倒计时、进入或停止冷却按钮、冷却提醒页签、冷却列表或冷却记录备份。升级后会一次性清理历史冷却存储；旧备份中的冷却字段会被忽略。

删除CD提醒不影响可转律资格、槽位状态、转律建议、最佳配装搜索和方案模拟。

### 8.2 旧“指定转律目标”入口停用

早期最佳配装中的单件“指定转律目标”路径不再作为正常入口。现在统一由三种转律搜索模式决定是否优化已转律装备或规划待转律装备，避免两套搜索状态互相影响。

### 8.3 不再使用旧等级规则

旧文档中“105级无限转律、100/96级一次转律”的说明已经废止。当前网站所有转律能力统一要求110级并明确勾选“可转律”。

## 九、常见问题

### 9.1 为什么110级装备没有转律选项？

110级只代表满足等级条件，还需要在装备编辑页勾选“可转律”。如果装备不是110级，勾选框不会显示。

### 9.2 承音装备能否转律？

可以。110级承音装备与普通110级装备遵守相同规则。

### 9.3 为什么某个目标词条没有出现？

常见原因包括：目标会与装备另一条副词条重复、目标是其他流派属性攻击、装备未勾选可转律、已转律装备选择了错误槽位，或副词条记录已经失效。

### 9.4 为什么建议保留原词条？

转律不是必然提升。网站始终把原词条作为候选；在当前整套装备和计算环境中原词条毕业率最高时，保持或切回就是正确建议。

### 9.5 方案里的转律结果会改坏装备库吗？

不会。方案保存的是临时计算覆盖层，装备库仍保留游戏中的原始词条和真实转律状态。

### 9.6 主页词条数量按哪套装备统计？

按当前方案真正用于计算的装备统计。存在有效转律模拟时显示替换后的词条数量；定音和贷款定音不计入40条普通词条。

## 十、术语速查

| 术语 | 含义 |
| --- | --- |
| 可转律 | 110级装备在网站中明确记录了游戏转律资格 |
| 待转律 | 有资格，但还没有指定副词条槽位 |
| 已转律 | 已指定一个有效副词条槽位，可在合法目标与原词条之间切换 |
| 转律库／武库 | 提供转律目标的词条池；网站允许合并使用其他流派武库 |
| 转律变体 | 仅在计算中把指定副词条替换为某个合法目标形成的临时装备 |
| 待转律规划 | 最佳配装为待转律装备规划的槽位与目标，不代表游戏已经完成操作 |
| 方案覆盖层 | 随装备方案保存的非破坏性转律模拟，不改写装备库 |
| 原始装备ID | 用于把原装、需承音形态和转律变体识别为同一件物理装备的稳定ID |
